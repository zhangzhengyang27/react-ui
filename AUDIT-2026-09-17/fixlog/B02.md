## 续修背景与关键发现

前 agent 已完成 14 条中 12 条的主体改动(未提交),但存在一处 **P0 级残余缺陷**:

- **B02-1 残余死循环**:Modal/Drawer 的栈注册 effect 依赖数组保留了整个 `stackCtx`,而 ModalStack/DrawerStack 的 context value(useMemo)依赖 `stack`——注册本身改变 `stack` 身份 → context value 身份变化 → effect cleanup(removeModal)+setup(addModal)重跑 → stack 身份再变,无限循环。前 agent 的新增测试 `ModalStack.test.tsx` 在 `act()` 内同步旋转(vitest worker 单核持续 30%+ CPU),连 vitest 的 testTimeout 都无法触发,表现为测试**永久挂起**。
- 本轮修复:effect 依赖改为只取 Stack 侧 `useCallback` 的稳定句柄 `stackCtx?.addModal` / `stackCtx?.removeModal`(不在依赖里放整个 stackCtx),Modal.tsx 与 Drawer.tsx 同步修正。修后测试 1 秒内通过。
- 另:前 agent 新增的两处测试(Menu 子菜单测试、ModalStack 测试)断言均在点击打开后立即同步查询,而弹层内容经 Transition 双重 requestAnimationFrame 才挂载(mounted→entered),本轮统一改为 `async` + `await screen.findByText(...)`。
