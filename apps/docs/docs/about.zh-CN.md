# 关于 ReactUI

ReactUI 是一个 React 组件库，专注于提供出色的用户体验和开发体验。它基于 ReactUI 架构演进而来，包含丰富的组件和 hooks，适用于从原型到生产的各类项目。

## 项目信息

ReactUI 由小叶（xiaoye）开发维护，所有包均遵循 [semver](https://semver.org/) 语义化版本规范：

- 补丁版本（0.0.X）修复 bug
- 次版本（0.X.0）新增功能，向后兼容
- 主版本（X.0.0）包含破坏性变更

## 技术栈

- **React 19** — 使用最新 React 特性
- **TypeScript** — 完整类型支持
- **CSS Modules** — 样式隔离与 CSS 变量系统
- **Floating UI** — 浮动元素定位
- **Embla Carousel** — 轮播组件
- **Recharts** — 图表组件
