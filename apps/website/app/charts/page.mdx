# Charts 图表

`@react-ui/ui` 的 Charts 组件（如 `LineChart`、`BarChart`、`PieChart` 等）目前处于规划阶段。
在正式发布前，你可以使用 `@react-ui/ui` 的布局与容器组件（`Paper`、`Stack`、`Text` 等）配合第三方图表库来构建图表页面。

## 与 Recharts 集成

下面是一个使用 [Recharts](https://recharts.org/) 的示例代码。
仓库当前未安装 `recharts`，但你可以把它加入自己的项目后直接使用。

```tsx
import { LineChart, Line, XAxis, YAxis, CartesianGrid, Tooltip, ResponsiveContainer } from 'recharts'
import { Paper, Stack, Text } from '@react-ui/ui'

const data = [
    { name: '1月', value: 400 },
    { name: '2月', value: 300 },
    { name: '3月', value: 600 },
    { name: '4月', value: 800 }
]

export default function SalesChart() {
    return (
        <Stack>
            <Text size="lg" fw={600}>
                月度销售额
            </Text>
            <Paper withBorder style={{ padding: 24, height: 320 }}>
                <ResponsiveContainer width="100%" height="100%">
                    <LineChart data={data}>
                        <CartesianGrid strokeDasharray="3 3" />
                        <XAxis dataKey="name" />
                        <YAxis />
                        <Tooltip />
                        <Line type="monotone" dataKey="value" stroke="var(--ui-color-blue-6)" strokeWidth={2} />
                    </LineChart>
                </ResponsiveContainer>
            </Paper>
        </Stack>
    )
}
```

## 未来 Charts 组件规划

| 组件           | 适用场景 | 预期核心 props                             |
| -------------- | -------- | ------------------------------------------ |
| `LineChart`    | 折线趋势 | `data`、`dataKey`、`series`、`curveType`   |
| `AreaChart`    | 面积趋势 | `data`、`dataKey`、`series`、`gradient`    |
| `BarChart`     | 柱状对比 | `data`、`dataKey`、`series`、`orientation` |
| `PieChart`     | 占比分布 | `data`、`nameKey`、`valueKey`              |
| `DonutChart`   | 环形占比 | `data`、`nameKey`、`valueKey`、`thickness` |
| `ScatterChart` | 散点关系 | `data`、`xAxisKey`、`yAxisKey`             |
| `RadarChart`   | 雷达多维 | `data`、`dataKey`、`series`                |

## 配色与主题适配

推荐在 Recharts 等库中使用 `@react-ui/ui` 的 CSS 变量，使图表颜色自动跟随主题切换：

```css
:root {
    --chart-color-1: var(--ui-color-blue-6);
    --chart-color-2: var(--ui-color-grape-6);
    --chart-color-3: var(--ui-color-teal-6);
}
```

```tsx
<Line stroke="var(--chart-color-1)" />
<Bar fill="var(--chart-color-2)" />
```

这样当用户切换暗色/亮色主题或修改主色时，图表配色会保持一致。

## 推荐第三方方案

-   [Recharts](https://recharts.org/)：基于 D3 的声明式 React 图表库，生态成熟。
-   [Chart.js](https://www.chartjs.org/) + [react-chartjs-2](https://react-chartjs-2.js.org/)：轻量、配置灵活。
-   [Victory](https://formidable.com/open-source/victory/)：专注于跨平台 React 组件的图表库。
