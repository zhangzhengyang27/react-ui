# Badge

徽章用于展示状态、文本标签或计数。

## 何时使用

当需要高亮显示状态、分类、标签或短文本提示时使用 Badge 组件。

## 基础使用

<Demo
    title="基础用法"
    description="Badge 基础用法"
    code={`import { Badge } from '@react-ui/ui'

export default function BadgeBasicDemo() {
    return <Badge>新消息</Badge>
}`}
>
    <BasicDemo />
</Demo>
