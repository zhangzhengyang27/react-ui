# Button

按钮用于开始一个即时操作。

## 何时使用

通常在需要用户鼠标交互的场景下，我们会选择使用按钮组件。

## 基础使用

<Demo
    title="基础用法"
    description="按钮组件基础使用示例"
    code={`import { Button } from '@react-ui/ui'

export default function BasicDemo() {
    return <Button variant="default">请点击</Button>
}`}
>
    <BasicDemo />
</Demo>

## 按钮变体

<Demo
    title="按钮变体"
    description="通过 variant 属性切换不同视觉风格，满足多种场景需求。"
    code={`import { Button, Group } from '@react-ui/ui'

const VARIANTS = ['default', 'filled', 'gradient', 'light', 'outline', 'subtle', 'transparent', 'white']

export default function ButtonVariantDemo() {
    return (
        <Group>
            {VARIANTS.map(variant => (
                <Button key={variant} variant={variant}>
                    {variant}
                </Button>
            ))}
        </Group>
    )
}`}
>
    <VariantDemo />
</Demo>
