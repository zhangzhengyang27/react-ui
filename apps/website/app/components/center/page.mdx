# Center

Center 用于将其子元素在容器内水平和垂直居中。

## 何时使用

当需要将内容在父容器中完全居中时使用 Center。

## 基础使用

<Demo
    title="基础用法"
    description="Center 基础用法"
    code={`import { Center, Box } from '@react-ui/ui'

export default function CenterBasicDemo() {
    return (
        <Box style={{ height: 120, background: 'var(--mantine-color-gray-2)' }}>
            <Center>
                <Box>居中对齐</Box>
            </Center>
        </Box>
    )
}`}

</Demo>
