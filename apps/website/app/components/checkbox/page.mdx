# Checkbox

复选框用于在多个选项中进行选择，或用于开启/关闭某个单独选项。

## 何时使用

- 需要从一组选项中选择一个或多个选项时。
- 需要在表单中表示布尔值开关（例如同意协议、启用通知）时。
