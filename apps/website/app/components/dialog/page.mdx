# Dialog

Dialog 是基于 ModalBase 的轻量确认/信息对话框，适合简单的确认、提示场景。

## 何时使用

当需要向用户展示重要信息、请求确认或执行轻量交互，但不需要复杂抽屉/模态框结构时使用 Dialog。
