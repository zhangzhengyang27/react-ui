# Fieldset

Fieldset 用于将一组相关表单控件分组展示，支持标题（legend）和整体禁用。

## 基础使用

<Demo
    title="字段分组"
    description="使用 legend 设置分组标题，内部可放置任意表单组件。"
    code={`import { Fieldset, TextInput } from '@react-ui/ui'

export default function FieldsetBasicDemo() {
    return (
        <Fieldset legend="个人信息">
            <TextInput label="姓名" placeholder="请输入姓名" />
            <TextInput label="邮箱" placeholder="请输入邮箱" style={{ marginTop: 12 }} />
        </Fieldset>
    )
}`}
>
    <BasicDemo />
</Demo>
