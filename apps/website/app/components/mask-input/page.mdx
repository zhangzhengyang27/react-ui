# MaskInput

MaskInput 用于按固定格式输入内容，例如手机号、日期、证件号等。使用 `#` 表示任意字符占位。

## 基础使用

<Demo
    title="手机号格式"
    description="通过 mask 属性定义格式，onChange 返回去除格式符号的原始值。"
    code={`import { useState } from 'react'
import { MaskInput } from '@react-ui/ui'

export default function MaskInputBasicDemo() {
    const [value, setValue] = useState('')

    return <MaskInput label="手机号" mask="(###) ####-####" placeholder="请输入手机号" value={value} onChange={setValue} />
}`}
>
    <BasicDemo />
</Demo>

## 自定义占位符

<Demo
    title="自定义占位符"
