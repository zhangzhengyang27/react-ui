# PasswordInput

PasswordInput 是带密码可见性切换功能的输入框组件。

## 何时使用

当需要用户输入密码、密钥等敏感信息时，可使用 PasswordInput 组件。组件内置显示/隐藏密码的切换按钮，方便用户确认输入内容。
