# PinInput

PinInput 组件用于输入验证码、PIN 码等分段短码，支持数字/字母、自动聚焦、粘贴填充和掩码显示。

## 基础使用

<Demo
    title="基础用法"
    description="默认 4 位分段输入，输入单个字符后自动聚焦到下一个输入框。"
    code={`import { PinInput } from '@react-ui/ui'

export default function PinInputBasicDemo() {
    return <PinInput length={4} placeholder="〇" />
}`}
>
    <BasicDemo />
</Demo>

## 数字类型

<Demo
    title="仅允许数字"
    description="将 type 设置为 number，可限制输入框只接收数字字符。"
    code={`import { PinInput } from '@react-ui/ui'

export default function PinInputNumberDemo() {
    return <PinInput type="number" length={6} placeholder="-" />
}`}
>
    <NumberDemo />
</Demo>

## 掩码显示

<Demo
    title="掩码输入"
    description="开启 mask 后，输入内容将以圆点显示，适合密码类场景。"
    code={`import { PinInput } from '@react-ui/ui'

export default function PinInputMaskedDemo() {
    return <PinInput mask length={4} placeholder="*" />
}`}
>
    <MaskedDemo />
</Demo>
