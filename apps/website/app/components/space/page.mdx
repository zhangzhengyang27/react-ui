# Space

Space 用于在元素之间创建固定大小的空白间距。

## 何时使用

当需要在垂直或水平方向上快速添加固定间距时使用 Space。

## 基础使用

<Demo
    title="基础用法"
    description="Space 基础用法"
    code={`import { Space, Box } from '@react-ui/ui'

export default function SpaceBasicDemo() {
    return (
        <>
            <Box>上方内容</Box>
            <Space h="md" />
            <Box>下方内容</Box>
        </>
    )
}`}
