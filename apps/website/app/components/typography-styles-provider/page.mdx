# TypographyStylesProvider

TypographyStylesProvider 用于为 HTML 富文本内容提供统一的排版样式，常用于渲染 Markdown、编辑器输出等。

## 何时使用

当需要渲染不可控的 HTML 内容，并希望其与组件库主题保持一致时使用。
