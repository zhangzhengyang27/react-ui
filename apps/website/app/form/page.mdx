# Form 组件

`@react-ui/ui` 的 Form 相关组件（如 `TextInput`、`Select`、`Checkbox`、`Radio` 等）目前正在规划中。
在正式发布前，你可以使用现有布局组件配合原生表单元素，或者与社区成熟的表单方案结合使用。

## 与 React Hook Form 集成

下面是一个未引入 `react-hook-form` 的“纯布局”示例，展示如何用 `Stack`、`Group`、`Button`、`Text` 快速搭建一个注册表单。
当你引入 `react-hook-form` 或类似库后，只需把 `register` / `control` 绑定到对应输入上即可。

### 接入验证的示例

```tsx
import { useForm } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'
import * as z from 'zod'
import { Button, Stack, Text } from '@react-ui/ui'

const schema = z.object({
    email: z.string().email(),
    password: z.string().min(6)
})

export default function LoginForm() {
    const {
        register,
        handleSubmit,
        formState: { errors }
    } = useForm({ resolver: zodResolver(schema) })

    return (
        <form onSubmit={handleSubmit(console.log)}>
            <Stack>
                <input {...register('email')} placeholder="邮箱" />
                {errors.email && <Text color="red">{errors.email.message}</Text>}
                <input type="password" {...register('password')} placeholder="密码" />
                {errors.password && <Text color="red">{errors.password.message}</Text>}
                <Button type="submit">登录</Button>
            </Stack>
        </form>
    )
}
```

## 未来 Form 组件规划

| 组件                     | 用途         | 预期核心 props                                                 |
| ------------------------ | ------------ | -------------------------------------------------------------- |
| `TextInput`              | 单行文本输入 | `label`、`placeholder`、`description`、`error`、`withAsterisk` |
| `Textarea`               | 多行文本输入 | `label`、`autosize`、`minRows`、`maxRows`、`error`             |
| `Select`                 | 单选下拉     | `data`、`label`、`placeholder`、`clearable`、`searchable`      |
| `MultiSelect`            | 多选下拉     | `data`、`maxSelectedValues`、`searchable`                      |
| `Autocomplete`           | 自动补全     | `data`、`filter`、`limit`                                      |
| `Checkbox`               | 复选框       | `label`、`indeterminate`、`error`                              |
| `Radio` / `RadioGroup`   | 单选组       | `name`、`labelPosition`                                        |
| `Switch`                 | 开关         | `label`、`onLabel`、`offLabel`                                 |
| `Slider` / `RangeSlider` | 滑块         | `min`、`max`、`step`、`marks`                                  |
| `NumberInput`            | 数字输入     | `min`、`max`、`step`、`decimalScale`                           |
| `PasswordInput`          | 密码输入     | `visibilityToggleIcon`                                         |
| `PinInput`               | 验证码输入   | `length`、`type`、`manageFocus`                                |

## 推荐第三方方案

-   [React Hook Form](https://react-hook-form.com/)：性能优异、无冗余重渲染的表单状态管理库。
-   [Zod](https://zod.dev/) / [Yup](https://github.com/jquense/yup)：类型安全的 schema 校验，配合 resolver 使用。
-   [Formik](https://formik.org/)：如果你需要一套更完整的表单上下文方案。
