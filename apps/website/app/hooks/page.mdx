# Hooks

`@react-ui/hooks` 提供了一系列常用的 React Hooks，帮助你更高效地处理状态管理、UI 交互、生命周期和 DOM 操作。

<div style={{ display: 'flex', gap: 12, marginTop: 24, flexWrap: 'wrap' }}>
    <Button component="a" href="/components/button">
        浏览组件
    </Button>
</div>

## 状态管理

- [useDisclosure](/hooks/use-disclosure) — 控制布尔开关状态
- [useCounter](/hooks/use-counter) — 计数器状态管理
- [useUncontrolled](/hooks/use-uncontrolled) — 受控/非受控组件状态管理

## UI 交互

- [useClipboard](/hooks/use-clipboard) — 剪贴板复制操作
- [useClickOutside](/hooks/use-click-outside) — 监听元素外部点击
- [useFocusTrap](/hooks/use-focus-trap) — 焦点捕获
- [useCollapse](/hooks/use-collapse) — 折叠动画
- [useMediaQuery](/hooks/use-media-query) — 响应式媒体查询

## 生命周期

- [useDidUpdate](/hooks/use-did-update) — 组件更新时执行副作用
- [useIsomorphicEffect](/hooks/use-isomorphic-effect) — 同构渲染的 effect
- [useReducedMotion](/hooks/use-reduced-motion) — 检测用户是否偏好减少动画

## Refs

- [useCallbackRef](/hooks/use-callback-ref) — 稳定的回调 ref
- [useMergedRef](/hooks/use-merged-ref) — 合并多个 ref

## 工具

- [useColorScheme](/hooks/use-color-scheme) — 检测系统颜色主题
- [useId](/hooks/use-id) — 生成唯一 ID
