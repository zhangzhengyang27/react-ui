# useDidUpdate

在依赖变化时执行副作用，跳过首次渲染（与 componentDidUpdate 语义一致）。 对齐 mantine useDidUpdate。

## 使用示例

<Demo
    title="基础用法"
    description="useDidUpdate 基础使用示例"
    themeToggle
    rtl
    code={`import { useDidUpdate } from '@react-ui/hooks'

export default function Example() {
    const result = useDidUpdate(fn)
    return <div>{JSON.stringify(result)}</div>
}`}
>
    <HookExample hook="useDidUpdate" />
</Demo>
