# useReducedMotion

检测用户是否开启了「减少动态效果」系统偏好（prefers-reduced-motion: reduce）。 对齐 mantine useReducedMotion。

## 使用示例

<Demo
    title="基础用法"
    description="useReducedMotion 基础使用示例"
    themeToggle
    rtl
    code={`import { useReducedMotion } from '@react-ui/hooks'

export default function Example() {
    const result = useReducedMotion()
    return <div>{JSON.stringify(result)}</div>
}`}
>
    <HookExample hook="useReducedMotion" />
</Demo>
