# @react-ui/ui

小叶科技官方 React UI 组件库，用于学员参考学习。基于 React 19 + TypeScript，
借鉴 Mantine 架构，提供主题、Styles API 与丰富的可组合组件。

## 特性

- 🎨 **主题系统**：提供浅色/深色主题、颜色、间距、圆角等设计令牌
- 🧩 **Styles API**：通过 `classNames`、`styles`、`vars` 精细定制组件样式
- 🏢 **企业级**：符合企业级组件库研发标准，架构借鉴 Mantine
- 🚀 **持续更新**：组件库内容逐步更新，可持续跟进
