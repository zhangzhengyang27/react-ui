# CSS Modules

`@react-ui/ui` 使用 CSS Modules 管理组件样式，确保样式隔离，避免全局命名冲突。

## 约定

每个组件目录下包含一个 `{Component}.module.css` 文件，例如：

```
Button/
  Button.tsx
  Button.module.css
```

## 静态类名

支持 Styles API 的组件会自动生成静态类名，格式为 `mantine-{ComponentName}-{selector}`，
例如 Button 的 root 元素会带有 `mantine-Button-root` 类。

```css
.mantine-Button-root {
    text-transform: uppercase;
}
```

> 推荐优先使用 `classNames` 而不是全局 CSS 选择器，以避免样式冲突。
