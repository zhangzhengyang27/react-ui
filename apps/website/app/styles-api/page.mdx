# Styles API

Styles API 是一组用于自定义 `@react-ui/ui` 组件内部元素样式的属性与技术。
你可以通过组件 `classNames`、`styles`、`vars` 属性，或在 `theme.components` 中统一配置，实现细粒度的样式覆盖。

## 核心能力

- **Selectors** — 组件内部元素名称，如 Button 的 `root`、`inner`、`label`
- **CSS 变量** — 通过 `vars` 覆盖组件内部 CSS 变量
- **CSS Modules** — 组件样式隔离机制
- **响应式样式** — 基于断点的样式调整
- **Data 属性** — 通过 `data-*` 属性控制状态样式
- **变体与尺寸** — `variant` 和 `size` 的工作方式

## 推荐定制路径

面对不同的样式需求，可以按以下优先级选择方案：

1. **`classNames`**：需要覆盖组件内部某个 selector 的样式，且样式规则较简单时优先使用。
2. **`vars`**：需要修改组件内部 CSS 变量（如颜色、圆角、间距）时使用，语义最清晰。
3. **`styles`**：需要根据 props 动态计算样式，或做一次性局部调整时使用。
4. **`theme.components`**：需要全局统一某个组件的默认 props / classNames / vars 时使用。

## classNames 示例

<Demo
    title="classNames 用法"
    description="为 Button 的不同 selector 添加自定义类名。"
    code={`import { Button } from '@react-ui/ui'

function Demo() {
    return (
        <Button
            classNames={{
                root: 'my-root-class',
                label: 'my-label-class'
            }}
        >
            Styled Button
        </Button>
    )
}`}
>
    <div style={{ padding: 24, textAlign: 'center', color: 'var(--nextra-secondary-color, #888)' }}>
        将上方代码复制到项目中即可预览效果
    </div>
</Demo>

```css
.my-root-class {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    border: none;
}

.my-label-class {
    font-weight: 700;
    letter-spacing: 0.05em;
}
```
