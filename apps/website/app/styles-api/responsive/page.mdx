# 响应式样式

主题对象中的 `breakpoints` 定义了响应式断点。你可以在 `styles` 函数或内联 `style` 中根据窗口尺寸返回不同样式。

## 断点配置

```tsx
{
    breakpoints: {
        xs: '36em',
        sm: '48em',
        md: '62em',
        lg: '75em',
        xl: '88em'
    }
}
```

## 使用媒体查询

```tsx
import { Button } from '@react-ui/ui'

function Demo() {
    return (
        <Button
            styles={{
                root: {
                    width: '100%',
                    '@media (min-width: 48em)': {
                        width: 'auto'
                    }
                }
            }}
        >
            Responsive Button
        </Button>
    )
}
```

## 推荐实践

- 优先使用主题断点常量，避免在业务代码里写死 `48em`。
- 对于布局变化（如 Grid 列数），使用响应式 props 或 CSS Grid 媒体查询。
- 对于组件尺寸，优先通过 `size` 控制，而不是直接写死 `width`。
