# 变体与尺寸

组件的 `variant`、`size` 和 `radius` 属性通过 CSS 变量和 classNames 组合实现视觉变化。
它们的最终解析顺序是：

1. **组件调用时的 props**（局部最高优先级）
2. **`theme.components.<Component>.defaultProps`**（全局覆盖）
3. **组件内部默认值**（由主题或组件内部决定）
4. **`styles` / `classNames` / `vars`**（在这些 props 之上再做样式微调）

简单记忆：越靠近调用处的配置优先级越高。

## 变体

以 Button 为例，支持的 variant 包括：

- `default`
- `filled`
- `light`
- `outline`
- `subtle`
- `transparent`
- `white`
- `gradient`

## 尺寸

`size` 属性通常映射到主题中的 `spacing`、`fontSizes`、`radius` 等令牌。以 Button 为例：

| size | 典型应用 |
| --- | --- |
| `xs` | 极小按钮、标签内操作 |
| `sm` | 表格行内操作 |
| `md` | 默认，大多数场景 |
| `lg` | 突出 CTA |
| `xl` | 全屏大按钮、营销页 |

## radius

`radius` 与 `size` 独立，控制组件圆角。当 `radius` 未提供时，组件通常会回退到 `theme.defaultRadius`。
