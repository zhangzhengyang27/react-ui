# 颜色方案

`@react-ui/ui` 支持浅色（light）和深色（dark）两种颜色方案。通过 `Provider` 的 `colorScheme` 属性可以强制指定当前方案。

## 强制指定颜色方案

<Demo
    title="深色模式"
    description="在 Provider 上强制使用 dark 颜色方案。"
    code={`import { Provider, Button } from '@react-ui/ui'

function Demo() {
    return (
        <Provider colorScheme="dark">
            <Button>Dark Mode Button</Button>
        </Provider>
    )
}`}
>

## 与系统主题同步

结合 `useColorScheme` hook 可以监听系统主题变化：

```tsx
import { Provider } from '@react-ui/ui'
import { useColorScheme } from '@react-ui/hooks'

function App() {
    const colorScheme = useColorScheme()
    return <Provider colorScheme={colorScheme}>{/* ... */}</Provider>
}
```

## CSS 变量

颜色方案通过 `:root[data-ui-color-scheme]` 属性切换 CSS 变量实现。
