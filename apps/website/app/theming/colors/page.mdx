# 颜色系统

主题对象中的 `colors` 字段定义了所有可用的颜色令牌。每种颜色包含 10 个色阶（0-9），0 最浅，9 最深。

## 预置颜色

`@react-ui/ui` 默认提供多种颜色：

- `dark`、`gray`
- `red`、`pink`、`grape`、`violet`、`indigo`、`blue`、`cyan`
- `teal`、`green`、`lime`、`yellow`、`orange`

## 自定义颜色

通过 `theme.colors` 添加自定义颜色，然后在组件中使用：

## primaryColor

`primaryColor` 设置全局主色，影响 `Button`、`ActionIcon`、`Loader` 等组件的默认颜色。必须是 `theme.colors` 中已定义的颜色键名。

## primaryShade

`primaryShade` 控制使用主色的哪个色阶。可设置为数字 `0-9`，或分别为浅色/深色模式指定：

```tsx
{
    primaryShade: { light: 6, dark: 8 }
}
```
