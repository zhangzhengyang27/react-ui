# 主题配置

`@react-ui/ui` 的主题系统借鉴 Mantine，通过 `Provider` 的 `theme` 属性统一管理颜色、字体、间距、圆角、阴影等设计令牌。

## 核心概念

-   **主题对象** — 包含所有设计令牌的结构化对象
-   **颜色系统** — 基于色阶的颜色配置与主色管理
-   **颜色方案** — light / dark 模式切换
-   **字体排版** — 字体、标题、行高配置
-   **默认属性** — 通过 `theme.components` 统一设置组件默认 props

## 基础用法

通过 `Provider` 包裹应用并传入 `theme` 覆盖对象，覆盖对象会与默认主题深度合并。

<Demo
    title="自定义主题"
    description="修改主色与圆角，观察组件外观变化。"
    code={`import { Provider, Button, Group } from '@react-ui/ui'

function Demo() {
return (
<Provider
theme={{
                primaryColor: 'cyan',
                defaultRadius: 'xl'
            }} >
<Group>
<Button variant="filled">Cyan Button</Button>
<Button variant="outline">Outline</Button>
</Group>
</Provider>
)
}`}
