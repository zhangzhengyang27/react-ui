# 字体排版

主题对象中的 `fontFamily`、`fontFamilyMonospace` 和 `headings` 字段控制全局字体和标题样式。

## 字体配置

```tsx
{
    fontFamily: '-apple-system, BlinkMacSystemFont, Segoe UI, Roboto, sans-serif',
    fontFamilyMonospace: 'ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace'
}
```

## 标题样式

`headings` 配置 h1-h6 的字体、字重和尺寸：

<Demo
    title="自定义标题"
    description="覆盖标题字体和尺寸。"
    code={`import { Provider, Title } from '@react-ui/ui'

function Demo() {
    return (
        <Provider
            theme={{
                headings: {
                    fontFamily: 'Georgia, serif',
                    fontWeight: '700',
                    sizes: {
                        h1: { fontSize: '2.5rem', lineHeight: '1.2' }
                    }
                }
            }}
        >
            <Title order={1}>Custom Heading</Title>
        </Provider>
    )
}`}
>
    <div style={{ padding: 24, textAlign: 'center', color: 'var(--nextra-secondary-color, #888)' }}>
        将上方代码复制到项目中即可预览效果
    </div>
</Demo>

## 字体大小与行高

`fontSizes` 和 `lineHeights` 定义了组件中可使用的文本尺寸令牌。

```tsx
{
    fontSizes: { xs: '0.75rem', sm: '0.875rem', md: '1rem', lg: '1.125rem', xl: '1.25rem' },
    lineHeights: { xs: 1.4, sm: 1.45, md: 1.55, lg: 1.6, xl: 1.65 }
}
```
