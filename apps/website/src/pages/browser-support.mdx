# 浏览器支持

ReactUI 在以下浏览器中经过测试：Chrome、Safari、Firefox、Edge、iOS Safari、Android Chrome。

## 支持的浏览器

ReactUI 的所有组件和 hooks 在以下浏览器中测试通过：

- Chromium 浏览器 108+ — Chrome、Edge、Android Chrome 等
- Firefox 101+
- Safari 15.4+
- 不支持 IE（任何版本）

ReactUI 样式依赖 [:where 选择器](https://caniuse.com/mdn-css_selectors_where) 和 [@layer 指令](https://caniuse.com/mdn-css_at-rules_layer)，低于以下版本可能存在样式问题：

- Chromium 浏览器 99+
- Firefox 97+
- Safari 15.4+

## CSS 特性

ReactUI 组件使用以下 CSS 特性：

- [:where 选择器](https://caniuse.com/mdn-css_selectors_where) — 所有组件
- [@layer 指令](https://caniuse.com/mdn-css_at-rules_layer) — 所有样式
- [:has 伪类](https://caniuse.com/css-has) — 部分组件的非关键样式
- [flexbox gap](https://caniuse.com/flexbox-gap) — 大部分组件
- [dvh 单位](https://caniuse.com/mdn-css_types_length_viewport_percentage_units_dynamic) — 部分组件
- [aspect-ratio](https://caniuse.com/mdn-css_properties_aspect-ratio) — 部分组件
- [container queries](https://caniuse.com/css-container-queries) — 部分组件（显式启用时）

以上所有 CSS 特性在现代浏览器中均已支持（截至 2024 年 1 月，全球使用率 90%+）。

## Polyfills

ReactUI 默认不包含任何 polyfill，如需支持旧版浏览器请手动安装。通常，框架的打包工具（webpack、vite 等）会根据 browserslist 配置自动添加 polyfill。
