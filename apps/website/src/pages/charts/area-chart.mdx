## 用法

在不使用 `type` 属性的情况下使用 `AreaChart` 组件，可渲染常规面积图。在常规面积图中，每个数据系列独立绘制，互不交互。

<Demo data={AreaChartDemos.usage} />

## 堆叠面积图

设置 `type="stacked"` 以渲染堆叠面积图。在此类型中，堆叠沿垂直轴应用，使你既能看到总体趋势，也能看到每个系列对总数的贡献。

<Demo data={AreaChartDemos.stacked} />

## 百分比面积图

设置 `type="percent"` 以渲染百分比面积图。在此类型中，Y 轴刻度始终归一化为 100%，便于比较各系列在百分比方面的贡献。

<Demo data={AreaChartDemos.percent} />

## 分割面积图

设置 `type="split"` 以渲染分割面积图。在此类型中，填充颜色分为两种：一种用于正值，一种用于负值。分割面积图仅支持一个数据系列。

<Demo data={AreaChartDemos.split} />

## 分割颜色

将 `splitColors` 属性设置为包含两种颜色的数组，以自定义分割面积图的填充颜色。第一种颜色用于正值，第二种颜色用于负值。`splitColors` 属性在其他类型的面积图中会被忽略。

<Demo data={AreaChartDemos.splitColors} />

## 图例

要显示图表图例，设置 `withLegend` 属性。当悬停在图例中的某一项时，图表中对应的数据系列会高亮显示。

<Demo data={AreaChartDemos.legend} />

## 图例位置

你可以通过 `legendProps` 属性向 recharts 的 [Legend](https://recharts.org/en-US/api/Legend) 组件传递属性。例如，设置 `legendProps={{ verticalAlign: 'bottom', height: 50 }}` 会将图例渲染在图表底部，并设置其高度为 50px。

<Demo data={AreaChartDemos.legendPosition} />

## 系列标签

默认情况下，使用系列对象的 `name` 作为标签。要更改标签，请在 `series` 对象中设置 `label` 属性：

<Demo data={AreaChartDemos.seriesLabels} />

## 为每条线设置曲线类型

你可以在 `series` 数组中为每条线设置独立的曲线类型。如果没有为某条线设置曲线类型，该系列将回退到 `curveType` 属性，若未设置 `curveType`，则默认为 `monotone`。

<Demo data={AreaChartDemos.curveType} />

## 连接空值

使用 `connectNulls` 属性指定是否跨空值连接数据点。默认情况下，`connectNulls` 为 `true`。

<Demo data={AreaChartDemos.connectNulls} />

要在数据点上显示标签，设置 `withPointLabels`：

<Demo data={AreaChartDemos.pointLabels} />

使用 `xAxisProps` 和 `yAxisProps` 向 recharts 的 [XAxis](https://recharts.org/en-US/api/XAxis) 和 [YAxis](https://recharts.org/en-US/api/YAxis) 组件传递属性。例如，可以使用这些属性来更改坐标轴方向：

<Demo data={AreaChartDemos.axisProps} />

## Y 轴刻度

使用 `yAxisProps` 更改 Y 轴的取值范围。例如，如果你知道数据始终在 0 到 100 之间，可以将 domain 设置为 `[0, 100]`：

<Demo data={AreaChartDemos.yScale} />

## 右侧 Y 轴

要在图表右侧显示额外的 Y 轴，设置 `withRightYAxis` 属性。你可以通过 `rightYAxisProps` 属性向 recharts 的 [YAxis](https://recharts.org/en-US/api/YAxis) 组件传递属性，并通过 `rightYAxisLabel` 属性为右侧 Y 轴设置标签。注意，你需要在 `series` 对象中设置 `yAxisId`，将数据系列绑定到右侧 Y 轴。

<Demo data={AreaChartDemos.rightYAxis} />

## 旋转 X 轴标签

要旋转 X 轴标签，将 `xAxisProps.angle` 设置为需要旋转的度数：

<Demo data={AreaChartDemos.rotateLabels} />

## 数值格式化

要格式化提示框和坐标轴刻度中的数值，使用 `valueFormat` 属性。它接受一个函数，该函数接收数值参数并返回格式化后的值：

<Demo data={AreaChartDemos.valueFormatter} />

## 区域颜色

你可以像其他组件一样从 [主题](/theming/theme-object) 中引用颜色，例如 `blue`、`red.5`、`orange.7` 等。任何有效的 CSS 颜色值也同样受支持。

<Demo data={AreaChartDemos.color} />

## 根据颜色方案改变区域颜色

你可以在 `color` 属性中使用 CSS 变量。要定义随颜色方案变化的 CSS 变量，可使用 [light/dark mixins](/styles/postcss-preset/#dark-and-light-mixins) 或 [light-dark 函数](/styles/postcss-preset/#light-dark-function)。例如，一个区域在浅色模式下为深橙色，在深色模式下为柠檬色：

<Demo data={AreaChartDemos.colorSchemeColor} />

## 虚线数组

设置 `strokeDasharray` 属性以控制网格线和光标线的虚线样式。该值表示交替的虚线和间隙长度。例如，`strokeDasharray="10 5"` 会渲染出 10px 虚线和 5px 间隙的虚线。

<Demo data={AreaChartDemos.strokeDasharray} />

## 网格和文本颜色

使用 `--chart-grid-color` 和 `--chart-text-color` 来更改网格线和图表内文本的颜色。配合 [CSS 模块](/styles/css-modules/)，你可以根据颜色方案改变颜色：

<Demo data={AreaChartDemos.gridColor} />

如果你的应用只使用一种颜色方案，可以直接使用 `gridColor` 和 `textColor` 属性，而不必使用 CSS 变量：

```tsx
import { AreaChart } from '@react-ui/ui';
import { data } from './data';

function Demo() {
  return (
    <AreaChart
      h={300}
      data={data}
      dataKey="date"
      type="stacked"
      gridColor="gray.5"
      textColor="gray.9"
      series={[
        { name: 'Apples', color: 'indigo.6' },
        { name: 'Oranges', color: 'blue.6' },
        { name: 'Tomatoes', color: 'teal.6' },
      ]}
    />
  );
}
```
