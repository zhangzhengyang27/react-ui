## 用法

在不使用 `type` 属性的情况下使用 `BarChart` 组件，可渲染常规柱状图。在常规柱状图中，每个数据系列独立绘制，互不交互。

<Demo data={BarChartDemos.usage} />

## 堆叠柱状图

设置 `type="stacked"` 以渲染堆叠柱状图。在此类型中，堆叠沿垂直轴应用，使你既能看到总体趋势，也能看到每个系列对总数的贡献。

<Demo data={BarChartDemos.stacked} />

## 混合堆叠柱状图

你可以通过在 series 对象中设置 `stackId` 属性来控制系列的堆叠方式：

<Demo data={BarChartDemos.mixedStack} />

## 百分比柱状图

设置 `type="percent"` 以渲染百分比柱状图。在此类型中，Y 轴刻度始终归一化为 100%，便于比较各系列在百分比方面的贡献。

<Demo data={BarChartDemos.percent} />

## 瀑布柱状图

设置 `type="waterfall"` 以渲染瀑布柱状图。此图表类型展示初始值如何受到后续正值或负值的影响，每个柱子从上一个柱子结束的位置开始。使用数据中的 `color` 属性为每个柱子单独着色。注意，该柱子的系列颜色会被覆盖。使用数据中的 `standalone` 属性可将柱子从流程中解耦。

<Demo data={BarChartDemos.waterfall} />

## SVG 图案作为柱体填充

你可以使用 SVG 图案作为柱体填充。为此，将 series 对象中的 `fill` 属性设置为图表 `children` 中 `defs` 区域定义的 SVG 图案的 URL。

使用对角条纹和交叉线图案作为柱体填充的示例：

<Demo data={BarChartDemos.stripes} />

## 根据数值设置柱体颜色

使用 `getBarColor` 属性根据数值分配颜色。`getBarColor` 函数接收两个参数：数值和系列对象。它应返回一个颜色字符串（主题颜色引用或任意有效的 CSS 颜色值）。

注意，`getBarColor` 返回的颜色不会影响图例和提示框的颜色。

<Demo data={BarChartDemos.getBarColor} />

## 图例

要显示图表图例，设置 `withLegend` 属性。当悬停在图例中的某一项时，图表中对应的数据系列会高亮显示。

<Demo data={BarChartDemos.legend} />

## 图例位置

你可以通过 `legendProps` 属性向 recharts 的 [Legend](https://recharts.org/en-US/api/Legend) 组件传递属性。例如，设置 `legendProps={{ verticalAlign: 'bottom', height: 50 }}` 会将图例渲染在图表底部，并设置其高度为 50px。

<Demo data={BarChartDemos.legendPosition} />

## 根据颜色方案改变柱体颜色

你可以在 `color` 属性中使用 CSS 变量。要定义随颜色方案变化的 CSS 变量，可使用 [light/dark mixins](/styles/postcss-preset/#dark-and-light-mixins) 或 [light-dark 函数](/styles/postcss-preset/#light-dark-function)。例如，一个柱体在浅色模式下为深橙色，在深色模式下为柠檬色：

<Demo data={BarChartDemos.colorSchemeColor} />

## 虚线数组

设置 `strokeDasharray` 属性以控制网格线和光标线的虚线样式。该值表示交替的虚线和间隙长度。例如，`strokeDasharray="10 5"` 会渲染出 10px 虚线和 5px 间隙的虚线。

<Demo data={BarChartDemos.strokeDasharray} />

## 网格和文本颜色

使用 `--chart-grid-color` 和 `--chart-text-color` 来更改网格线和图表内文本的颜色。配合 [CSS 模块](/styles/css-modules/)，你可以根据颜色方案改变颜色：

<Demo data={BarChartDemos.gridColor} />

如果你的应用只使用一种颜色方案，可以直接使用 `gridColor` 和 `textColor` 属性，而不必使用 CSS 变量：

```tsx
import { BarChart } from '@react-ui/ui';
import { data } from './data';

function Demo() {
  return (
    <BarChart
      h={300}
      data={data}
      dataKey="date"
      type="stacked"
      gridColor="gray.5"
      textColor="gray.9"
      series={[
        { name: 'Smartphones', color: 'violet.6' },
        { name: 'Laptops', color: 'blue.6' },
        { name: 'Tablets', color: 'teal.6' },
      ]}
    />
  );
}
```
