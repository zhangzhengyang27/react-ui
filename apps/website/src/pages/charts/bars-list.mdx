## 用法

`BarsList` 组件展示一组带名称和数值的条形。唯一必需的属性是 `data`——一个包含 `name` 和 `value` 属性的对象数组。

<Demo data={BarsListDemos.usage} />

## 数据格式

`BarsList` 期望的数据格式如下：

```tsx
export const data = [
  { name: 'React', value: 950000 },
  { name: 'Vue', value: 320000 },
  { name: 'Angular', value: 580000 },
  { name: 'Svelte', value: 145000 },
];
```
