## 用法

`CompositeChart` 允许在同一个图表中组合使用 `Line`、`Area` 和 `Bar` 图表：

<Demo data={CompositeChartDemos.usage} />

## 图例

要显示图表图例，设置 `withLegend` 属性。当悬停在图例中的某一项时，图表中对应的数据系列会高亮显示。

<Demo data={CompositeChartDemos.legend} />

## 图例位置

你可以通过 `legendProps` 属性向 recharts 的 [Legend](https://recharts.org/en-US/api/Legend) 组件传递属性。例如，设置 `legendProps={{ verticalAlign: 'bottom', height: 50 }}` 会将图例渲染在图表底部，并设置其高度为 50px。

<Demo data={CompositeChartDemos.legendPosition} />

## 系列标签

默认情况下，使用系列对象的 `name` 作为标签。要更改标签，请在 `series` 对象中设置 `label` 属性：

<Demo data={CompositeChartDemos.seriesLabels} />

## 数据点标签

要在数据点上显示标签，设置 `withPointLabels`。此功能仅支持 `Line` 和 `Area` 图表：

<Demo data={CompositeChartDemos.pointLabels} />

## X 轴和 Y 轴属性

使用 `xAxisProps` 和 `yAxisProps` 向 recharts 的 [XAxis](https://recharts.org/en-US/api/XAxis) 和 [YAxis](https://recharts.org/en-US/api/YAxis) 组件传递属性。例如，可以使用这些属性来更改坐标轴方向：

<Demo data={CompositeChartDemos.axisProps} />

## 坐标轴标签

使用 `xAxisLabel` 和 `yAxisLabel` 属性显示坐标轴标签：

<Demo data={CompositeChartDemos.axisLabels} />

## X 轴偏移

使用 `xAxisProps` 设置图表两端与 X 轴之间的间距：

<Demo data={CompositeChartDemos.xAxisOffset} />

## Y 轴刻度

使用 `yAxisProps` 更改 Y 轴的取值范围。例如，如果你知道数据始终在 0 到 100 之间，可以将 domain 设置为 `[0, 100]`：

<Demo data={CompositeChartDemos.yScale} />

## 右侧 Y 轴

要在图表右侧显示额外的 Y 轴，设置 `withRightYAxis` 属性。你可以通过 `rightYAxisProps` 属性向 recharts 的 [YAxis](https://recharts.org/en-US/api/YAxis) 组件传递属性，并通过 `rightYAxisLabel` 属性为右侧 Y 轴设置标签。注意，你需要在 `series` 对象中设置 `yAxisId`，将数据系列绑定到右侧 Y 轴。

<Demo data={CompositeChartDemos.rightYAxis} />

## 旋转 X 轴标签

要旋转 X 轴标签，将 `xAxisProps.angle` 设置为需要旋转的度数：

<Demo data={CompositeChartDemos.rotateLabels} />

## 数值格式化

要格式化提示框和坐标轴刻度中的数值，使用 `valueFormat` 属性。它接受一个函数，该函数接收数值参数并返回格式化后的值：

<Demo data={CompositeChartDemos.valueFormatter} />

## 图表颜色

你可以像其他组件一样从 [主题](/theming/theme-object) 中引用颜色，例如 `blue`、`red.5`、`orange.7` 等。任何有效的 CSS 颜色值也同样受支持。

<Demo data={CompositeChartDemos.color} />

## 根据颜色方案改变图表颜色

你可以在 `color` 属性中使用 CSS 变量。要定义随颜色方案变化的 CSS 变量，可使用 [light/dark mixins](/styles/postcss-preset/#dark-and-light-mixins) 或 [light-dark 函数](/styles/postcss-preset/#light-dark-function)。例如，一个图表在浅色模式下为深橙色，在深色模式下为柠檬色：

<Demo data={CompositeChartDemos.colorSchemeColor} />

## 虚线数组

设置 `strokeDasharray` 属性以控制网格线和光标线的虚线样式。该值表示交替的虚线和间隙长度。例如，`strokeDasharray="10 5"` 会渲染出 10px 虚线和 5px 间隙的虚线。

<Demo data={CompositeChartDemos.strokeDasharray} />

## 网格和文本颜色

使用 `--chart-grid-color` 和 `--chart-text-color` 来更改网格线和图表内文本的颜色。配合 [CSS 模块](/styles/css-modules/)，你可以根据颜色方案改变颜色：

<Demo data={CompositeChartDemos.gridColor} />

如果你的应用只使用一种颜色方案，可以直接使用 `gridColor` 和 `textColor` 属性，而不必使用 CSS 变量：

```tsx
import { CompositeChart } from '@react-ui/ui';
import { data } from './data';

function Demo() {
  return (
    <CompositeChart
      h={300}
      data={data}
      dataKey="date"
      gridColor="gray.5"
      textColor="gray.9"
      series={[
        { name: 'Apples', color: 'indigo.6', type: 'line' },
        { name: 'Oranges', color: 'blue.6', type: 'bar' },
        { name: 'Tomatoes', color: 'teal.6', type: 'area' },
      ]}
    />
  );
}
```

## 提示框动画

默认情况下，提示框动画处于禁用状态。要启用，请将 `tooltipAnimationDuration` 属性设置为动画持续毫秒数，以动画方式改变提示框位置。

<Demo data={CompositeChartDemos.tooltipAnimation} />

## 单位

设置 `unit` 属性，在 Y 轴刻度和提示框数值旁渲染单位标签：

<Demo data={CompositeChartDemos.unit} />

## 自定义提示框

使用 `tooltipProps.content` 向 recharts 的 [Tooltip](https://recharts.org/en-US/api/Tooltip) 组件传入自定义提示框渲染器。注意，必须使用 `getFilteredChartTooltipPayload` 函数过滤 recharts 的 payload，以移除仅用于样式的空值。

<Demo data={CompositeChartDemos.customTooltip} />

## 移除提示框

要移除提示框，设置 `withTooltip={false}`。这同时也会移除光标线，并禁用图表的交互。

<Demo data={CompositeChartDemos.noTooltip} />

## 自定义圆点

使用 `dotProps` 向 recharts 的普通状态圆点传递属性，使用 `activeDotProps` 向激活状态（光标位于当前系列上时）的圆点传递属性。

<Demo data={CompositeChartDemos.dotProps} />

## 描边宽度

使用 `strokeWidth` 属性控制所有区域/线条的描边宽度：

<Demo data={CompositeChartDemos.strokeWidth} />

## 同步多个图表

你可以通过 `composedChartProps` 属性向 recharts 的 [ComposedChart](https://recharts.org/en-US/api/ComposedChart) 组件传递属性。例如，设置 `composedChartProps={{ syncId: 'any-id' }}` 会同步多个具有相同 `syncId` 属性的 `CompositeChart` 组件的提示框。

<Demo data={CompositeChartDemos.sync} />
