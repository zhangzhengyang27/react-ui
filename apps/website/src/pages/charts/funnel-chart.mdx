## 用法

`FunnelChart` 基于 [FunnelChart recharts 组件](https://recharts.org/en-US/api/FunnelChart)：

<Demo data={FunnelChartDemos.usage} />

## 图例

要显示图例，设置 `withLegend` 属性。图例会展示每个分段的名称和颜色。悬停在图例项上可高亮对应分段：

<Demo data={FunnelChartDemos.legend} />

你可以通过 `legendProps` 属性向 recharts 的 `Legend` 组件传递属性。例如，设置 `legendProps={{ verticalAlign: 'top' }}` 可将图例显示在图表上方。

## 分段标签

设置 `withLabels` 属性以在每个分段旁显示标签。使用 `labelPosition` 属性控制标签相对于分段的位置。

<Demo data={FunnelChartDemos.withLabels} />

## 尺寸和粗细

设置 `size` 属性以控制图表的宽度和高度。你可以通过 `h` [样式属性](/styles/style-props) 覆盖此行为。

<Demo data={FunnelChartDemos.size} />

## 分段颜色

你可以像其他组件一样从 [主题](/theming/theme-object) 中引用颜色，例如 `blue`、`red.5`、`orange.7` 等。任何有效的 CSS 颜色值也同样受支持。

<Demo data={FunnelChartDemos.color} />

## 提示框数据源

默认情况下，悬停在任意分段上时，提示框会显示所有分段的数据。要仅显示悬停分段的数据，设置 `tooltipDataSource="segment"`：

<Demo data={FunnelChartDemos.tooltipDataSource} />

## 无提示框

要移除提示框，设置 `withTooltip={false}`：

<Demo data={FunnelChartDemos.noTooltip} />

## 分段描边

使用 `strokeWidth` 属性控制每个分段周围描边的宽度：

<Demo data={FunnelChartDemos.strokeWidth} />

要更改描边颜色，使用 `strokeColor` 属性。你可以像其他组件一样从 [主题](/theming/theme-object) 中引用颜色，例如 `blue`、`red.5`、`orange.7` 等。任何有效的 CSS 颜色值也同样受支持。

```tsx
import { FunnelChart } from '@react-ui/ui';

function Demo() {
  return <FunnelChart data={[]} strokeColor="red.5" />;
}
```

默认情况下，分段描边颜色与 body 元素的背景色相同（`--ui-color-body` CSS 变量）。如果你想根据颜色方案改变描边颜色，可以定义一个 CSS 变量并传递给 `strokeColor` 属性：

<Demo data={FunnelChartDemos.strokeColor} />
