## 用法

`PieChart` 基于 [PieChart recharts 组件](https://recharts.org/en-US/api/PieChart)：

<Demo data={PieChartDemos.usage} />

## 图例

要显示图例，设置 `withLegend` 属性。图例会展示每个分段的名称和颜色。悬停在图例项上可高亮对应分段：

<Demo data={PieChartDemos.legend} />

你可以通过 `legendProps` 属性向 recharts 的 `Legend` 组件传递属性。例如，设置 `legendProps={{ verticalAlign: 'top' }}` 可将图例显示在图表上方。

## 分段标签

设置 `withLabels` 属性以在每个分段旁显示标签。使用 `labelPosition` 属性控制标签相对于分段的位置。注意，如果图表分段很多且设置了 `labelPosition="inside"`，标签可能会重叠，此时请使用 `labelPosition="outside"`。

<Demo data={PieChartDemos.withLabels} />

## 尺寸

设置 `size` 属性以控制图表的宽度和高度。注意，如果设置了 `withLabels` 和 `labelPosition="outside"`，图表高度会自动增加 80px 以为标签留出空间。你可以通过 `h` 和 `w` [样式属性](/styles/style-props) 覆盖此行为。

<Demo data={PieChartDemos.size} />

## 分段颜色

你可以像其他组件一样从 [主题](/theming/theme-object) 中引用颜色，例如 `blue`、`red.5`、`orange.7` 等。任何有效的 CSS 颜色值也同样受支持。

<Demo data={PieChartDemos.color} />

## 启用提示框

要启用提示框，设置 `withTooltip` 属性：

<Demo data={PieChartDemos.tooltip} />

## 提示框数据源

默认情况下，悬停在任意分段上时，提示框会显示所有分段的数据。要仅显示悬停分段的数据，设置 `tooltipDataSource="segment"`：

<Demo data={PieChartDemos.tooltipDataSource} />

## 起始和结束角度

使用 `startAngle` 和 `endAngle` 属性控制图表的起始和结束角度。例如，要展示半圆图表，设置 `startAngle={180}` 和 `endAngle={0}`：

<Demo data={PieChartDemos.angle} />

请注意，即使设置了 `startAngle` 和 `endAngle` 属性，图表所占用的空间仍与完整圆形相同。

## 分段描边

使用 `strokeWidth` 属性控制每个分段周围描边的宽度：

<Demo data={PieChartDemos.strokeWidth} />

要更改描边颜色，使用 `strokeColor` 属性。你可以像其他组件一样从 [主题](/theming/theme-object) 中引用颜色，例如 `blue`、`red.5`、`orange.7` 等。任何有效的 CSS 颜色值也同样受支持。

```tsx
import { PieChart } from '@react-ui/ui';

function Demo() {
  return <PieChart data={[]} strokeColor="red.5" />;
}
```

默认情况下，分段描边颜色与 body 元素的背景色相同（`--ui-color-body` CSS 变量）。如果你想根据颜色方案改变描边颜色，可以定义一个 CSS 变量并传递给 `strokeColor` 属性：

<Demo data={PieChartDemos.strokeColor} />
