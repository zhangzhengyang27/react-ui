## 用法

`SankeyChart` 基于 [Sankey recharts 组件](https://recharts.org/en-US/api/Sankey)。它用于可视化节点之间的流量，每条连线的宽度与流量值成正比：

<Demo data={SankeyChartDemos.usage} />

## 节点颜色

你可以在数据的每个节点上设置 `color` 来控制单个节点颜色。颜色可以引用 [主题](/theming/theme-object) 值，例如 `blue`、`red.5`、`orange.7` 等。任何有效的 CSS 颜色值也同样受支持。

<Demo data={SankeyChartDemos.color} />

## 自定义颜色

使用 `colors` 属性提供一组颜色，当单个节点未设置 `color` 时用于节点。颜色可以引用 [主题](/theming/theme-object) 值。当节点数量多于颜色数量时，颜色会循环使用：

<Demo data={SankeyChartDemos.colors} />

## 节点宽度和间距

使用 `nodeWidth` 控制每个节点的宽度，使用 `nodePadding` 控制节点之间的间距：

<Demo data={SankeyChartDemos.nodeWidth} />

## 连线透明度

使用 `linkOpacity` 属性控制节点之间连线的透明度：

<Demo data={SankeyChartDemos.linkOpacity} />

## 禁用提示框

要禁用提示框，设置 `withTooltip={false}`：
