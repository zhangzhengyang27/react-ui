## 尺寸

你可以在 `size` 属性中使用任何有效的 CSS 值，该属性用于设置 `width`、`min-width`、`min-height` 和 `height`
属性。请注意，`size` 属性不会控制子元素[图标](/guides/icons)的大小——你需要
在图标组件上手动设置。当 `size` 为数字时，该值被视为 `px` 单位，并转换为 [rem](/styles/rem) 单位。

<Demo data={ActionIconDemos.size} />

如果你希望 `ActionIcon` 与 ReactUI 输入框大小相同，请使用 `size="input-sm"` 属性：

## 禁用状态

要使 `ActionIcon` 禁用，请设置 `disabled` 属性。这将阻止与按钮的任何交互
并添加禁用样式。如果你希望按钮看起来被禁用但仍可交互，
请改为设置 `data-disabled` 属性。请注意，所有变体的禁用样式都相同。

<Demo data={ActionIconDemos.disabled} />

## ActionIcon 作为链接时的禁用状态

`<a />` 元素不支持 `disabled` 属性。要在 `ActionIcon` 渲染为链接时禁用它，
请改为设置 `data-disabled` 属性，并在 `onClick` 事件处理函数中阻止默认行为。

<Demo data={ActionIconDemos.disabledLink} />

## 自定义禁用样式

要自定义禁用样式，建议同时使用 `&:disabled` 和 `&[data-disabled]`
选择器：

- `&:disabled` 用于在设置 `disabled` 属性时设置按钮样式，
  以及当父组件禁用按钮时（例如，当在包含 `ActionIcon` 的
  `<fieldset />` 元素上设置 `disabled` 属性时）。
- `&[data-disabled]` 用于在按钮实际上未被禁用但应看起来
  被禁用时设置样式（例如，如果你需要将 [Tooltip](/core/tooltip) 与禁用的 `ActionIcon` 一起使用，
  或当 `ActionIcon` 用作链接时，应使用 `data-disabled`）

<Demo data={ActionIconDemos.disabledStyles} />

## 带 Tooltip 的禁用按钮

`onMouseLeave` 事件在 `ActionIcon` 被禁用时[不会触发](https://github.com/facebook/react/issues/18753)，
因此如果你需要将 [Tooltip](/core/tooltip) 与禁用的 `ActionIcon` 一起使用，
需要在 `ActionIcon` 上设置 `data-disabled` 属性而不是 `disabled`。
同时还需要将 `onClick` 事件处理函数改为
`(event) => event.preventDefault()`，因为 `ActionIcon` 实际上并未禁用，仍会触发
`onClick` 事件。

<Demo data={ActionIconDemos.disabledTooltip} />

## ActionIcon.Group

<Demo data={ActionIconDemos.group} />

`ActionIcon.Group` 渲染时带有 `role="group"`。当该组合代表一组有意义的操作时，
请使用 `aria-label`（或 `aria-labelledby`）为其提供可访问名称，以便屏幕阅读器可以播报其用途：

```tsx
import { ActionIcon } from '@react-ui/ui';

function Demo() {
  return (
    <ActionIcon.Group aria-label="文本格式">
      {/* ...ActionIcon components */}
    </ActionIcon.Group>
  );
}
```

请注意，你不能用任何额外的元素包裹子 `ActionIcon` 组件：

```tsx
import { ActionIcon } from '@react-ui/ui';

// 将无法正常工作
function Demo() {
  return (
    <ActionIcon.Group>
      <div>
        <ActionIcon>这将不会生效</ActionIcon>
      </div>
      <ActionIcon>ActionIcon 会有不正确的边框</ActionIcon>
    </ActionIcon.Group>
  );
}
```

## 可访问性

要使 `ActionIcon` 对屏幕阅读器可访问，你需要设置 `aria-label` 或
使用 [VisuallyHidden](/core/visually-hidden) 组件：

```tsx
import { HeartIcon } from '@phosphor-icons/react';
import { ActionIcon, VisuallyHidden } from '@react-ui/ui';

function Demo() {
  return (
    <>
      <ActionIcon aria-label="点赞帖子">
        <HeartIcon />
      </ActionIcon>

      <ActionIcon>
        <VisuallyHidden>点赞帖子</VisuallyHidden>
        <HeartIcon />
      </ActionIcon>
    </>
  );
}
```
