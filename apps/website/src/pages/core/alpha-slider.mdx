## 用法

使用 `AlphaSlider` 组件允许用户选择颜色的 alpha（不透明度）值。
它接受 `0` 到 `1` 之间的值。`AlphaSlider` 是 [ColorPicker](/core/color-picker) 组件的一部分，
但也可以单独使用。
