## 下划线

使用 `underline` 属性配置 `text-decoration`。它接受以下值：

- `always` - 链接始终有下划线
- `hover` - 悬停时链接有下划线
- `never` - 链接永远没有下划线
- `not-hover` - 未悬停时链接有下划线

<Demo data={AnchorDemos.decoration} />

你还可以使用 [default props](/theming/default-props) 为所有 `Anchor` 组件配置 `underline` 属性：

```tsx
import { Anchor, createTheme, MantineProvider } from '@react-ui/ui';

const theme = createTheme({
  components: {
    Anchor: Anchor.extend({
      defaultProps: {
        underline: 'always',
      },
    }),
  },
});

function Demo() {
  return (
    <MantineProvider theme={theme}>
      {/* 你的应用内容 */}
    </MantineProvider>
  );
}
```
