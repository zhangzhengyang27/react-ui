## 首字母

要显示首字母而不是默认占位符，请将 `name` 属性
设置为人员姓名，例如 `name="John Doe"`。如果设置了姓名，
可以使用 `color="initials"` 根据姓名生成颜色：

<Demo data={AvatarDemos.initials} />

## 允许的首字母颜色

默认情况下，默认主题中的所有颜色都允许用于首字母。你可以通过提供
`allowedInitialsColors` 属性并传入颜色数组来限制它们。请注意，默认颜色
数组不包含主题中定义的自定义颜色——如果需要，你需要手动提供它们。

<Demo data={AvatarDemos.allowedColors} />

## Avatar.Group

`Avatar.Group` 组件将多个头像组合成一个堆叠：

<Demo data={AvatarDemos.group} />

请注意，你不能用任何额外的元素包裹子 `Avatar` 组件，
但可以用不在当前树中渲染任何 HTML 元素的组件包裹 `Avatar`，
例如 [Tooltip](/core/tooltip)。

```tsx
import { Avatar } from '@react-ui/ui';

// 将无法正常工作
function Demo() {
  return (
    <Avatar.Group spacing="sm">
      <div>
        <Avatar src="image.png" radius="xl" />
      </div>
      <Avatar src="image.png" radius="xl" />
      <Avatar src="image.png" radius="xl" />
      <Avatar radius="xl">+5</Avatar>
    </Avatar.Group>
  );
}
```

## 可访问性

Avatar 渲染一个 `<img />` HTML 元素。设置 `alt` 属性以描述图片——
当图片无法加载时，它也用作头像占位符的 `title` 属性。

```tsx
import { Avatar } from '@react-ui/ui';

function Demo() {
  // ❌ 图片没有 alt
  return <Avatar src="./image.png" />;

  // ✅ alt 已设置
  return <Avatar src="./image.png" alt="Rob Johnson" />;

  // ✅ title 不是必需的，但仍建议设置
  return <Avatar>RJ</Avatar>;

  // ✅ title 在占位符上设置
  return <Avatar alt="Rob Johnson">RJ</Avatar>;
}
```
