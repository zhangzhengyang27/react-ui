## 用法

`Box` 组件用作所有其他组件的基础。`Box` 支持以下功能：

- [component prop](/guides/polymorphic)
- [style props](/styles/style-props)
- [style prop](/styles/style)

你可以将 `Box` 用作自己组件的基础，或作为 HTML 元素的替代：

```tsx
import { Box } from '@react-ui/ui';

function Demo() {
  return (
    <Box bg="red.5" my="xl" component="a" href="/">
      My component
    </Box>
  );
}
```
