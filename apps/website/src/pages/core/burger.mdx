## 用法

`Burger` 组件渲染一个打开/关闭菜单按钮。
设置 `opened` 和 `onClick` 属性以控制组件状态。
如果设置了 `opened` 属性，将渲染一个叉号图标，否则渲染汉堡图标。

## 可访问性

要使 `Burger` 对屏幕阅读器可访问，你需要设置 `aria-label` 或
使用 [VisuallyHidden](/core/visually-hidden) 组件：

```tsx
import { Burger, VisuallyHidden } from '@react-ui/ui';

function Demo() {
  return (
    <>
      <Burger aria-label="Toggle navigation" />

      <Burger>
        <VisuallyHidden>Toggle navigation</VisuallyHidden>
      </Burger>
    </>
  );
}
```
