## 左右区域

`leftSection` 和 `rightSection` 允许在按钮的左侧和右侧添加图标或其他元素。
添加区域后，相应侧的内边距会减小。

注意，在 [RTL](/styles/rtl) 模式下 `leftSection` 和 `rightSection` 会互换
（`leftSection` 显示在右侧，`rightSection` 显示在左侧）。

<Demo data={ButtonDemos.sections} />

## 区域位置

`justify` 属性设置 `inner` 元素的 `justify-content`。你可以用它来更改
左右区域的对齐方式。例如，要将它们分散到按钮两端，可设置 `justify="space-between"`。

如果只需将单个区域对齐到按钮一侧，可将 `justify` 设置为 `space-between`，
并在对侧区域添加一个空的 `<span />`。

<Demo data={ButtonDemos.sectionsJustify} />

## 禁用状态

要使 `Button` 禁用，请设置 `disabled` 属性。这将阻止与按钮的任何交互，
并添加禁用样式。如果你希望按钮看起来被禁用但仍可交互，
请改用 `data-disabled` 属性。注意，禁用样式对所有变体都相同。

<Demo data={ButtonDemos.disabled} />

## 链接按钮的禁用状态

`<a />` 元素不支持 `disabled` 属性。要在 `Button` 渲染为链接时使其禁用，
请改用 `data-disabled` 属性，并在 `onClick` 事件处理程序中阻止默认行为。

<Demo data={ButtonDemos.disabledLink} />

## 自定义禁用样式

要自定义禁用样式，建议同时使用 `&:disabled` 和 `&[data-disabled]`
选择器：

- `&:disabled` 用于设置 `disabled` 属性时的按钮样式，
  以及父组件禁用按钮时的样式（例如，在包含 `Button` 的 `<fieldset />` 元素上设置 `disabled` 属性）。
- `&[data-disabled]` 用于按钮实际未被禁用但应看起来被禁用的样式
  （例如，需要在使用 [Tooltip](/core/tooltip) 时使用禁用的 `Button`，
  或当 `Button` 用作链接时）

<Demo data={ButtonDemos.disabledStyles} />

## 带 Tooltip 的禁用按钮

`Button` 禁用时不会触发 `onMouseLeave` 事件（[详见](https://github.com/facebook/react/issues/18753)），因此如果你需要将
[Tooltip](/core/tooltip) 与禁用的 `Button` 一起使用，需要在 `Button` 上设置 `data-disabled` 属性，
而不是 `disabled`。注意，还需要将 `onClick` 事件处理程序更改为
`(event) => event.preventDefault()`，因为 `Button` 实际上并未禁用，仍会触发
`onClick` 事件。

<Demo data={ButtonDemos.disabledTooltip} />

[Loader](/core/loader) 的颜色取决于 `Button` 的变体。

## Button.Group

<Demo data={ButtonDemos.group} />

注意，你不能用任何额外元素包裹子 `Button` 组件：

```tsx
import { Button } from '@react-ui/ui';

function Demo() {
  return (
    <Button.Group>
      <div>
        <Button>This will not work</Button>
      </div>
      <Button>Buttons will have incorrect borders</Button>
    </Button.Group>
  );
}
```
