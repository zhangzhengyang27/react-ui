## 受控模式

```tsx
import { useState } from 'react';
import { Chip } from '@react-ui/ui';

function Demo() {
  const [checked, setChecked] = useState(false);

  return (
    <Chip checked={checked} onChange={() => setChecked((v) => !v)}>
      My chip
    </Chip>
  );
}
```

## Chip.Group

`Chip.Group` 组件管理子 Chip 组件的状态。
设置 `multiple` 属性以允许同时选择多个 chip：

<Demo data={ChipDemos.group} />

## 受控 Chip.Group

```tsx
import { useState } from 'react';
import { Chip } from '@react-ui/ui';

function Single() {
  // multiple 为 false（默认）时值为字符串
  const [value, setValue] = useState('react');

  return (
    <Chip.Group multiple={false} value={value} onChange={setValue}>
      <Chip value="react">React</Chip>
      <Chip value="ng">Angular</Chip>
      <Chip value="svelte">Svelte</Chip>
      <Chip value="vue">Vue</Chip>
    </Chip.Group>
  );
}

function Multiple() {
  // multiple 为 true 时值为字符串数组
  const [value, setValue] = useState(['react']);

  return (
    <Chip.Group multiple value={value} onChange={setValue}>
      <Chip value="react">React</Chip>
      <Chip value="ng">Angular</Chip>
      <Chip value="svelte">Svelte</Chip>
      <Chip value="vue">Vue</Chip>
    </Chip.Group>
  );
}
```

## 可访问性

`Chip` 和 `Chip.Group` 组件默认具备可访问性——它们基于原生 radio/checkbox 输入构建，
所有键盘事件与原生控件的工作方式相同。
