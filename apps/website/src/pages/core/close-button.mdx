## 用法

`CloseButton` 渲染一个内部带有 `X` 图标的按钮。它用于其他 ReactUI 组件，如 [Drawer](/core/drawer) 或 [Modal](/core/modal)。

<Demo data={CloseButtonDemos.usage} />

## 修改图标

你可以通过向 `icon` 属性传递任何 React 节点来更改图标。
当 `CloseButton` 用作其他组件的一部分时很有用，
例如在 [Drawer](/core/drawer) 或 [Modal](/core/modal) 中。
请注意，如果你使用 `icon` 属性，`iconSize` 属性将被忽略——
你需要手动设置图标大小。

## 可访问性

要使 `CloseButton` 对屏幕阅读器可访问，你需要设置 `aria-label` 或
使用 [VisuallyHidden](/core/visually-hidden) 组件：

```tsx
import { CloseButton, VisuallyHidden } from '@react-ui/ui';

function Demo() {
  return (
    <>
      <CloseButton aria-label="Close modal" />

      <CloseButton>
        <VisuallyHidden>Close modal</VisuallyHidden>
      </CloseButton>
    </>
  );
}
```
