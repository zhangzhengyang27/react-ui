## 块级代码

要在 `pre` 元素中渲染代码，请将 `block` 属性传递给 Code 组件：

默认情况下，代码颜色为灰色。你可以将其更改为任何有效的 CSS 颜色或
[theme.colors](/theming/colors) 中的一种：

<Demo data={CodeDemos.colors} />
