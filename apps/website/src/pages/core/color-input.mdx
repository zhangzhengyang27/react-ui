## 加载状态

设置 `loading` 属性以显示加载指示器。默认情况下，加载器显示在输入框的右侧。
你可以使用 `loadingPosition` 属性将位置更改为 `'left'` 或 `'right'`。这对于 API 调用、搜索或验证等异步操作非常有用：

<Demo data={ColorInputDemos.loading} />

## 受控模式

```tsx
import { useState } from 'react';
import { ColorInput } from '@react-ui/ui';

function Demo() {
  const [value, setValue] = useState('');
  return <ColorInput value={value} onChange={setValue} />;
}
```

## 格式

该组件支持 hex、hexa、rgb、rgba、hsl 和 hsla 颜色格式。
仅对 hexa、rgba 和 hsla 格式显示更改不透明度的滑块：

<Demo data={ColorInputDemos.formatsConfigurator} />

## 保留无效输入

默认情况下，`ColorInput` 会在失焦时恢复为最后一个已知有效值。
要更改此行为并保留无效值，请设置 `fixOnBlur={false}`：

<Demo data={ColorInputDemos.fixOnBlur} />

## onChangeEnd

`onChangeEnd` 在用户停止拖动滑块或更改输入值时调用。
当你需要仅在用户完成与组件交互时才更新颜色时非常有用：

<Demo data={ColorInputDemos.onChangeEnd} />

## 禁用自由输入

要禁用自由输入，请设置 `disallowInput` 属性：

<Demo data={ColorInputDemos.disallowInput} />

## 使用色板

你可以添加任意数量的预定义颜色色板：

<Demo data={ColorInputDemos.swatches} />

默认情况下，每行显示 7 个色板。你可以使用 `swatchesPerRow` 属性更改此设置，
与 [ColorPicker](/core/color-picker/) 组件相同：

<Demo data={ColorPickerDemos.swatchesConfigurator} />

如果你需要将颜色选择限制为某些颜色——禁用颜色选择器、禁止自由输入
并隐藏取色器：

<Demo data={ColorInputDemos.swatchesOnly} />

## 点击颜色色板时关闭下拉框

要在点击某个颜色色板时关闭下拉框，请设置 `closeOnColorSwatchClick` 属性：

<Demo data={ColorInputDemos.closeOnColorSwatchClick} />

## 隐藏下拉框

要隐藏下拉框，请设置 `withPicker={false}`：

<Demo data={ColorInputDemos.withPicker} />

## 取色器

默认情况下，如果 [EyeDropper API](https://developer.mozilla.org/en-US/docs/Web/API/EyeDropper_API)
可用，取色器图标将显示在输入框的右侧区域。
要禁用它，请设置 `withEyeDropper={false}`：

<Demo data={ColorInputDemos.noEyeDropper} />
