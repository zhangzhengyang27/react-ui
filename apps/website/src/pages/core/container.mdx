## Grid 策略

从 8.2.0 开始，`Container` 支持 `strategy="grid"` 属性，启用更多
功能。

与默认的 `strategy="block"` 的区别：
- 使用 `display: grid` 而不是 `display: block`
- 不包含默认的内联内边距
- 不在根元素上设置 `max-width`（而是使用 grid template columns）

`strategy="grid"` 支持的功能：
- 支持 `strategy="block"` 的所有功能
- 带有 `data-breakout` 属性的子元素占据容器父元素的整个宽度
- `data-breakout` 内部带有 `data-container` 的子元素与主网格列具有相同宽度

## 用法

`Container` 将内容居中，并将其 `max-width` 限制为 `size` 属性指定的值。
注意，`size` 属性不会使 `max-width` 具有响应式。例如，
当设置为 `lg` 时，无论屏幕尺寸如何，它始终是 `lg`。

## 流式布局

设置 `fluid` 属性使容器变为流式。它将占据可用宽度的 100%，
这与设置 `size="100%"` 相同。
