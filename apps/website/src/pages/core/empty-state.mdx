## 用法

`EmptyState` 显示用于“无数据”情况的占位符：空搜索结果、空表格和列表、首次运行状态或带有可选操作调用的错误插图。
最简单的使用方式是使用 `icon`、`title` 和 `description` 属性：

<Demo data={EmptyStateDemos.usage} />

## 复合组件

要完全控制内容，请使用复合组件代替（或与）简写属性。
可用组件：

- `EmptyState.Indicator` – 图标或插图
- `EmptyState.Title` – 标题文本
- `EmptyState.Description` – 描述文本
- `EmptyState.Actions` – 操作按钮的包装器

<Demo data={EmptyStateDemos.compound} />

简写属性和复合组件可以混合使用。当同时提供时，`icon`、`title` 和 `description` 属性的内容先渲染，然后是 `children`：

```tsx
import { Button, EmptyState } from '@react-ui/ui';

function Demo() {
  return (
    <EmptyState icon={<Icon />} title="未找到结果">
      {/* 在标题之后渲染 */}
      <EmptyState.Actions>
        <Button variant="default">重置筛选</Button>
      </EmptyState.Actions>
    </EmptyState>
  );
}
```

## 对齐

设置 `align` 属性以控制内容的排列方式：

- `center`（默认）– indicator、title、description 和 actions 以居中的列堆叠
- `left` – indicator 放置在左侧，内容在其右侧对齐
- `right` – indicator 放置在右侧，内容在其左侧对齐

在上面的配置器中更改 `align` 属性以查看其效果。使用 `left` 和 `right`
对齐时，indicator 与内容顶部对齐。

## 变体

将 `variant` 属性设置为 `filled` 或 `light`，以将图标显示在彩色圆形 indicator 内。
使用 `color` 属性更改 indicator 颜色。如果未设置 `variant`，图标将以暗淡的颜色显示：

<Demo data={EmptyStateDemos.variant} />

## 尺寸

`EmptyState` 支持 `xs`、`sm`、`md`、`lg` 和 `xl` 尺寸。`size` 属性控制
indicator 尺寸、元素之间的间距以及 title 和 description 的字号。在上面的配置器中更改
`size` 属性以查看其缩放效果。

## Title 标题级别

默认情况下，`EmptyState.Title` 渲染一个没有语义标题级别的 `div` 元素。如果
空状态标题应该是标题，请设置 `order` 属性以将其渲染为 `h1`–`h6`
元素：

```tsx
import { EmptyState } from '@react-ui/ui';

function Demo() {
  return (
    <EmptyState>
      <EmptyState.Title order={2}>未找到结果</EmptyState.Title>
    </EmptyState>
  );
}
```

## 可访问性

- 根元素是一个普通的 `div`，没有被分配地标角色。
- `EmptyState.Title` 默认渲染非标题 `div`。如果标题
  应该作为标题暴露给辅助技术，请设置 `order` 属性。
- 操作按钮按提供的方式渲染——确保它们具有可访问标签。
