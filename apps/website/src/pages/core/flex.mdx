## 与 Group 和 Stack 的区别

`Flex` 组件是 [Group](/core/group/) 和 [Stack](/core/stack/) 的替代方案。
`Flex` 更灵活——它允许创建水平和垂直 flexbox 布局，但需要更多配置。
与 [Group](/core/group/) 和 [Stack](/core/stack/) 不同，`Flex` 是[多态组件](/guides/polymorphic/)并支持响应式属性。
