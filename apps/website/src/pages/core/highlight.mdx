## 用法

使用 Highlight 组件通过 HTML `<mark>` 元素高亮文本中的子字符串。

将文本作为 children 传递，并使用 `highlight` 属性指定要高亮的子字符串。
默认情况下匹配是**不区分大小写**和**不区分重音符号**的，并且会高亮
匹配子字符串的所有出现位置。使用 `caseInsensitive` 和 `accentInsensitive` 属性选择退出。

<Demo data={HighlightDemos.usage} />

## 匹配行为

- **不区分大小写**：'hello' 匹配 'Hello'、'HELLO'、'hElLo' 等（由 `caseInsensitive` 控制，默认为 `true`）
- **不区分重音符号**：'cafe' 匹配 'café'、'cafè'、'CAFÉ' 等（由 `accentInsensitive` 控制，默认为 `true`）
- **所有出现位置**：匹配子字符串的每个实例都会被高亮
- **特殊字符**：`[`、`]`、`(`、`)` 等正则特殊字符会自动转义并按字面文本处理
- **空白字符**：高亮字符串中的前导和尾随空白会被修剪并忽略
- **空字符串**：空字符串或仅包含空白的高亮字符串会被忽略

## 高亮多个子字符串

要高亮多个子字符串，请提供一个值数组。
当提供多个子字符串时，较长的匹配优先以避免部分重叠。

<Demo data={HighlightDemos.multiple} />

## 每个术语自定义颜色

你可以通过提供包含 `text` 和 `color` 属性的对象数组，为不同的高亮术语分配不同颜色：

## 整词匹配

使用 `wholeWord` 属性仅匹配完整单词。启用后，'the' 不会匹配 'there' 或 'theme'：

<Demo data={HighlightDemos.wholeword} />

## 更改高亮样式

可以使用 `highlightStyles` 属性覆盖默认 [Mark](/core/mark/) 样式，
它接受样式对象或接收主题作为参数并返回样式的函数：

<Demo data={HighlightDemos.styles} />

## Text 属性

Highlight 基于 [Text](/core/text/) 组件——除 `color` 外所有 Text 属性都可用。
使用 `color` 属性更改高亮背景颜色，而不是文本颜色。
