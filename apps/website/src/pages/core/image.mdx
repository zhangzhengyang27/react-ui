## 用法

`Image` 是对 `img` 的轻量封装，默认样式极少。默认情况下，图片
会占据父容器 100% 的宽度。可以使用 `w` 和 `h` [样式属性](/styles/style-props) 控制图片尺寸。

<Demo data={ImageDemos.usage} />

## 图片高度

大多数情况下，你需要设置图片高度以防止图片加载时出现布局跳动。可以通过 `h` [样式属性](/styles/style-props) 来设置。

<Demo data={ImageDemos.height} />

## 图片适应方式

默认情况下，图片使用 `object-fit: cover` 样式——它会缩放以覆盖父元素。要更改此行为，请设置 `w="auto"` 和 `fit="contain"` 属性。

## 与 Next.js Image 一起使用

`Image` 是一个[多态组件](/guides/polymorphic)，可以通过 `component` 属性更改其根元素。
你可以将它与 `next/image` 及其他类似组件一起使用。

```tsx
import NextImage from 'next/image';
import { Image } from '@react-ui/ui';
import myImage from './my-image.jpg';

function Demo() {
  return <Image component={NextImage} src={myImage} alt="我的图片" />;
}
```
