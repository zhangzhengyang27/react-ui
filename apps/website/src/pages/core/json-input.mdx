## 用法

`JsonInput` 基于 [Textarea](/core/textarea/) 组件。它内置 JSON 验证逻辑，并支持在失焦时格式化输入值：

<Demo data={JsonInputDemos.usage} />

## 加载状态

设置 `loading` 属性以显示加载指示器。默认情况下，加载器显示在输入框的右侧。你可以使用 `loadingPosition` 属性将位置更改为 `'left'` 或 `'right'`。这对于 API 调用、搜索或验证等异步操作非常有用：

<Demo data={JsonInputDemos.loading} />

## 受控模式

```tsx
import { useState } from 'react';
import { JsonInput } from '@react-ui/ui';

function Demo() {
  const [value, setValue] = useState('');
  return <JsonInput value={value} onChange={setValue} />;
}
```

## 非受控模式

`JsonInput` 可以像原生 `textarea` 元素一样用于非受控表单。设置 `name` 属性以在表单提交时将 JSON 输入值包含在 `FormData` 对象中。要在非受控表单中控制初始值，请使用 `defaultValue` 属性。

非受控 `JsonInput` 与 `FormData` 的示例用法：

```tsx
import { JsonInput } from '@react-ui/ui';

function Demo() {
  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        const formData = new FormData(event.currentTarget);
        console.log('JSON input value:', formData.get('data'));
      }}
    >
      <JsonInput
        label="Enter JSON"
        name="data"
        defaultValue="{}"
        formatOnBlur
      />
      <button type="submit">Submit</button>
    </form>
  );
}
```

## 自定义序列化

你可以提供自定义的 `serialize` 和 `deserialize` 函数，以支持标准 JSON 以外的数据格式。当你需要处理 `Date`、`Map`、`Set`、`undefined` 或其他不可 JSON 序列化的类型时，这非常有用。

下面的示例展示了如何使用 [superjson](https://github.com/blitz-js/superjson) 库处理扩展数据类型：

```tsx
import { useState } from 'react';
import { JsonInput } from '@react-ui/ui';
import superjson from 'superjson';

function Demo() {
  const [value, setValue] = useState(
    superjson.stringify(
      {
        name: 'John Doe',
        createdAt: new Date(),
        tags: new Set(['admin', 'user']),
        metadata: new Map([['role', 'developer']]),
      },
      null,
      2
    )
  );

  return (
    <JsonInput
      label="Extended JSON with superjson"
      description="Supports Date, Map, Set, BigInt, RegExp, and more"
      placeholder="Enter extended JSON"
      value={value}
      onChange={setValue}
      serialize={(val) => superjson.stringify(val, null, 2)}
      deserialize={superjson.parse}
      validationError="Invalid extended JSON format"
      formatOnBlur
      autosize
      minRows={6}
    />
  );
}
```

`deserialize` 函数在输入无效时必须抛出错误。当启用 `formatOnBlur` 时，`serialize` 和 `deserialize` 函数都会用于格式化。
