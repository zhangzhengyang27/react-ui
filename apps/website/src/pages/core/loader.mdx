## 用法

`Loader` 组件默认支持 3 种加载器类型：`oval`、`bars` 和 `dots`。所有
加载器均使用 CSS 动画以获得更好的性能。

<Demo data={LoaderDemos.configurator} />

## size 属性

你可以向 `size` 属性传递任何有效的 CSS 值或数字。数字会被视为 px，但会
转换为 [rem](/styles/rem)。例如，`size={32}` 会生成
`--loader-size: 2rem` CSS 变量。

## 添加自定义加载器

`Loader` 组件在其他组件中使用（如 [Button](/core/button)、[ActionIcon](/core/action-icon)、[LoadingOverlay](/core/loading-overlay) 等）。
你可以通过设置 `type` 使用[默认属性](/theming/default-props)来更改加载器类型。
你还可以使用 `loaders` [默认属性](/theming/default-props)添加自定义 CSS 或 SVG 加载器。

### 自定义纯 CSS 加载器

注意，为了让自定义加载器支持 `size` 和 `color` 属性，你需要在加载器样式中使用
`--loader-size` 和 `--loader-color` CSS 变量。

<Demo data={LoaderDemos.cssLoader} />

### 自定义 SVG 加载器

建议使用纯 CSS 加载器，因为基于 SVG 的动画可能存在以下问题：

- CPU 占用高——在低端设备上加载器可能会看起来卡顿
- 加载器动画可能要等到 JS 加载后才会开始播放——用户可能会看到静态加载器

在 SVG 加载器中，你需要像纯 CSS 自定义加载器一样使用 `--loader-size` 和 `--loader-color` 变量，
以使 `size` 和 `color` 属性生效。通常，你需要将 `width` 和 `height` 设置为 `var(--loader-size)`，
将 `fill`/`stroke` 设置为 `var(--loader-color)`。

<Demo data={LoaderDemos.customType} />

## children 属性

`Loader` 支持 `children` 属性。如果你向 `children` 传递任何内容，它会替代加载器渲染。
当你希望在使用 `loaderProps` 的组件中控制 `Loader` 的展示形式时，这很有用，
例如 [Button](/core/button/)、[LoadingOverlay](/core/loading-overlay/)、[Dropzone](/x/dropzone/)。
