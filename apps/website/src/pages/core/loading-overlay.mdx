## 用法

`LoadingOverlay` 会在具有相对定位的父元素上渲染一个带加载器的遮罩层。
它通常用于指示表单的加载状态。
注意，遮罩层下方的元素仍可通过键盘聚焦，因此请记住添加额外逻辑来处理这种情况。

`LoadingOverlay` 的渲染由 `visible` 属性控制：

## 自定义行内加载器

要将默认加载器替换为任何自定义内容，请设置 `loaderProps={{ children: <div>你的内容</div> }}`。
你可以在 `loaderProps.children` 中放置任何 React 节点：
