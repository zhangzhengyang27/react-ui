## 用法

Notification 是通知系统的基础组件。你可以基于它构建自己的通知系统，或使用 [@react-ui/ui](/x/notifications/) 包。

<Demo data={NotificationDemos.configurator} />

## 通知系统功能

当你使用 [@react-ui/ui](/x/notifications/) 时，通知可以通过以下方式关闭：

- 向左或向右拖动
- 悬停时水平滚动滑动手势

你可以在 `Notifications` 组件上使用 `allowDragDismiss={false}` 和 `allowScrollDismiss={false}` 禁用这些交互。

有关配置详情，请参阅 [notifications 包文档](/x/notifications/)。

## 可访问性

为了支持屏幕阅读器，请使用 `closeButtonProps` 设置关闭按钮的 aria-label 或 title：

```tsx
import { Notification } from '@react-ui/ui';

function Demo() {
  return (
    <Notification
      closeButtonProps={{ 'aria-label': '隐藏通知' }}
    />
  );
}
```
