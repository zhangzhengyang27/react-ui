# ReactUI Core components

[![npm](https://img.shields.io/npm/dm/@react-ui/ui)](https://www.npmjs.com/package/@react-ui/ui)

[@react-ui/ui](https://www.npmjs.com/package/@react-ui/ui) package
provides essential components: buttons, inputs, modals, typography, and many others.
The `@react-ui/ui` package is used internally in most of the other `@mantine/*` packages –
it is required to be installed in your project to use ReactUI components.
