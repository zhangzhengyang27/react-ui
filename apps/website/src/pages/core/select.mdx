## 用法

`Select` 允许根据列表建议捕获用户输入。
与 [Autocomplete](/core/autocomplete/) 不同，`Select` 不允许输入自定义值。

<Demo data={SelectDemos.usage} />

## 加载状态

设置 `loading` 属性以显示加载指示器。默认情况下，加载器显示在输入框右侧。
这对于 API 调用、搜索或验证等异步操作非常有用：

<Demo data={SelectDemos.loading} />

## 受控

`Select` 的值必须是原始类型（string、number 或 boolean）。
`onChange` 函数以原始值作为唯一参数被调用。

```tsx
import { useState } from 'react';
import { Select } from '@react-ui/ui';

function Demo() {
  const [value, setValue] = useState<string | null>('');
  return <Select data={[]} value={value} onChange={setValue} />;
}
```

## onChange 处理函数

`onChange` 以两个参数被调用：

- `value` - 选中选项的字符串值
- `option` – 选中的选项对象

如果你更喜欢在状态中使用对象格式，请使用 onChange 处理函数的第二个参数：

```tsx
import { useState } from 'react';
import { ComboboxItem, Select } from '@react-ui/ui';

function Demo() {
  const [value, setValue] = useState<ComboboxItem | null>(null);
  return (
    <Select
      data={[{ value: 'react', label: 'React library' }]}
      value={value ? value.value : null}
      onChange={(_value, option) => setValue(option)}
    />
  );
}
```

## 受控搜索值

你可以使用 `searchValue` 和 `onSearchChange` 属性控制搜索值：

```tsx
import { useState } from 'react';
import { Select } from '@react-ui/ui';

function Demo() {
  const [searchValue, setSearchValue] = useState('');
  return (
    <Select
      searchable
      searchValue={searchValue}
      onSearchChange={setSearchValue}
      data={[]}
    />
  );
}
```

## 选中选项图标

将 `checkIconPosition` 属性设置为 `left` 或 `right` 以控制活动选项中勾选图标的位置。
要移除勾选图标，请设置 `withCheckIcon={false}`。要让未选中标签与已选中标签对齐，请设置 `withAlignedLabels` 属性。

<Demo data={SelectDemos.checkIcon} />

## 值类型

`Select` 支持原始值（字符串、数字、布尔值）作为值类型。`Select` 会自动
推断值类型。如果你想显式设置值类型，请传递类型参数：

```tsx
import { Select } from '@react-ui/ui';

type SelectValue = 'React' | 'Angular' | 'Svelte' | number;

function Demo() {
  return <Select<SelectValue> data={['React', 'Angular', 'Svelte', 100]} />;
}
```

## renderOption

`renderOption` 回调允许你自定义选项渲染。它接收一个选项对象和
选中状态作为参数。该函数必须返回一个 React 节点。

<Demo data={SelectDemos.renderOption} />

## 可滚动下拉框

默认情况下，选项列表会包裹在 [ScrollArea.Autosize](/core/scroll-area) 中。
如果你未更改默认设置，可以使用 `maxDropdownHeight` 属性控制下拉框最大高度。

如果你想使用原生滚动条，请设置 `withScrollArea={false}`。注意，在这种情况下，
你需要使用 [Styles API](/styles/styles-api) 更改下拉框样式。

<Demo data={SelectDemos.scrollArea} />

## 适配视口高度

设置 `floatingHeight="viewport"` 使下拉框增长到填充视口中可用的垂直
空间。此模式下 `flip` 中间件被禁用——下拉框始终在配置的方向打开，
并被限制在视口边缘而不是翻转到另一侧。适用于处理大型选项列表：

<Demo data={SelectDemos.floatingHeight} />

## 分组选项

<Demo data={SelectDemos.groups} />

`group` 属性接受任何 React 节点，因此你可以将自定义标记
（图标、徽标、样式化文本）渲染为分组标签，而不仅仅是纯字符串。这同样适用于
`MultiSelect`、`Autocomplete` 和 `TagsInput`。注意，
`NativeSelect` 渲染原生 `optgroup` 元素，仅支持字符串分组标签。

## 下拉框位置

默认情况下，如果下方有足够空间，下拉框会显示在输入框下方；否则显示在输入框上方。
你可以通过设置 `position` 和 `middlewares` 属性来更改此行为，这些属性会传递给底层的
[Popover](/core/popover) 组件。

## 防止水平无限滚动

如果你在下拉框中遇到水平无限滚动，请将 `shift` 中间件的 `padding` 设置为 `0`：

```tsx
import { Select } from '@react-ui/ui';

function Demo() {
  return (
    <Select
      data={['React', 'Angular', 'Vue']}
      comboboxProps={{
        middlewares: {
          shift: { padding: 0 }
        }
      }}
    />
  );
}
```
