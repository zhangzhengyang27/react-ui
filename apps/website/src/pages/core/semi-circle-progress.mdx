## 更改空段颜色

使用 `emptySegmentColor` 属性更改空段颜色，
它接受 `theme.colors` 的键或任何有效的 CSS 颜色值：

<Demo data={SemiCircleProgressDemos.emptySegmentColor} />

## 更改标签位置

默认情况下，标签显示在组件底部，
你可以使用 `labelPosition` 属性将其位置更改为 `center`：

<Demo data={SemiCircleProgressDemos.labelPosition} />
