## 获取步骤 ref

你可以获取步骤按钮和 stepper 根元素（div）的 ref：

```tsx
import { useRef } from 'react';
import { Stepper } from '@react-ui/ui';

function MyStepper() {
  const firstStep = useRef<HTMLButtonElement>(null);
  const stepper = useRef<HTMLDivElement>(null);

  return (
    <Stepper ref={stepper} active={0}>
      <Stepper.Step label="First step" ref={firstStep} />
      <Stepper.Step label="Second step" />
    </Stepper>
  );
}
```

## 包裹 Stepper.Step

`Stepper` 组件依赖 `Stepper.Step` 的顺序。不支持包裹 `Stepper.Step`。相反，你需要使用不同的方法：

```tsx
import { Stepper } from '@react-ui/ui';

// 这不会生效，step 子项不会渲染
function WillNotWork() {
  return (
    <Stepper.Step label="Nope" description="It will not work">
      This part will not render
    </Stepper.Step>
  );
}

// 为子项创建一个单独的组件
function WillWork() {
  return <div>This will work as expected!</div>;
}

function Demo() {
  return (
    <Stepper active={1}>
      <Stepper.Step label="Regular step">First step</Stepper.Step>
      {/* 包裹的 Stepper.Step 不会渲染子项，不要这样做 */}
      <WillNotWork />
      <Stepper.Step label="Step with custom content">
        <WillWork />
      </Stepper.Step>
      <Stepper.Step label="Regular step">Third step</Stepper.Step>
    </Stepper>
  );
}
```

## 可访问性

`<Stepper.Step />` 组件渲染一个 button 元素；如果你没有指定 `label` 或 `description`，请设置 `aria-label` 或 `title` 属性以使屏幕阅读器可以识别该组件：

```tsx
import { Stepper } from '@react-ui/ui';

function Demo() {
  return (
    <Stepper active={0}>
      {/* 不好，屏幕阅读器没有标签 */}
      <Stepper.Step />

      {/* 好，有 label 和 description */}
      <Stepper.Step label="Step 1" description="Create an account" />

      {/* 好，有 aria-label */}
      <Stepper.Step aria-label="Create an account" />
    </Stepper>
  );
}
```

## 键盘导航

Stepper 支持完整的键盘导航：

- **Tab / Shift+Tab** - 在可点击步骤之间移动焦点
- **Space / Enter** - 激活获得焦点的步骤
- 每个步骤都是带有适当 ARIA 属性的 button 元素

不可点击的非活动步骤在 Tab 导航中会被跳过。tabIndex 会根据步骤是否可点击自动管理。
