## 加载状态

设置 `loading` 属性以显示加载指示器。默认情况下，加载器显示在输入框右侧。
你可以使用 `loadingPosition` 属性将其位置更改为 `'left'` 或 `'right'`。这对于 API 调用、搜索或验证等异步操作非常有用：

## 受控

```tsx
import { useState } from 'react';
import { TextInput } from '@react-ui/ui';

function Demo() {
  const [value, setValue] = useState('');
  return (
    <TextInput
      value={value}
      onChange={(event) => setValue(event.currentTarget.value)}
    />
  );
}
```

## 非受控

`TextInput` 可以像原生 `input[type="text"]` 一样用于非受控表单。
设置 `name` 属性以在表单提交时将文本输入值包含在 `FormData` 对象中。
要控制非受控表单中的初始值，请使用 `defaultValue` 属性。

非受控 `TextInput` 与 `FormData` 的用法示例：

```tsx
import { TextInput } from '@react-ui/ui';

function Demo() {
  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        const formData = new FormData(event.currentTarget);
        console.log('Text input value:', formData.get('name'));
      }}
    >
      <TextInput label="输入你的姓名" name="name" />
      <button type="submit">提交</button>
    </form>
  );
}
```
