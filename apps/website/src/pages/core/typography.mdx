## 用法

ReactUI 不包含排版全局样式。
使用 `Typography` 为你的 HTML 内容添加排版样式：

```tsx
import { Typography } from '@react-ui/ui';

function Demo() {
  return (
    <Typography>
      <div
        dangerouslySetInnerHTML={{ __html: '<p>Your html here</p>' }}
      />
    </Typography>
  );
}
```

## 全部样式演示

`Typography` 包含以下样式：

- 段落
- 标题
- 列表
- 引用块
- 表格
- 链接
- 图片
- 水平分割线
- 键盘按键
- 代码和预格式化文本
