## 用法

`VisuallyHidden` 是一个工具组件，用于在视觉上隐藏内容，但保留给屏幕阅读器访问。

例如，它可以与 [ActionIcon](/core/action-icon) 组件一起使用：

```tsx
import { HeartIcon } from '@phosphor-icons/react';
import { ActionIcon, VisuallyHidden } from '@react-ui/ui';

function Demo() {
  return (
    <ActionIcon>
      <HeartIcon />
      <VisuallyHidden>Like post</VisuallyHidden>
    </ActionIcon>
  );
}
```
