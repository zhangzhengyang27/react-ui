# ReactUI form

[![npm](https://img.shields.io/npm/dm/@react-ui/ui)](https://www.npmjs.com/package/@react-ui/ui)

[@react-ui/ui](https://www.npmjs.com/package/@react-ui/ui) 包
包含 `useForm` Hook，用于管理表单状态、验证和提交。
`useForm` Hook 设计用于与其他 ReactUI 库（`@react-ui/ui`、`@react-ui/ui` 等）配合使用——
所有 ReactUI 输入组件都与 `useForm` 开箱即用兼容。

## 安装

<InstallScript packages="@react-ui/ui" />

## 用法

`@react-ui/ui` 包可以在任何 Web React 应用中使用。
虽然该包设计用于与 ReactUI 组件一起工作，但它也可以
与原生输入框或任何其他表单库一起使用——它是独立的，除了 React 之外没有任何依赖。
