# ReactUI hooks

[![npm](https://img.shields.io/npm/dm/@react-ui/hooks)](https://www.npmjs.com/package/@react-ui/hooks)

The [@react-ui/hooks](https://www.npmjs.com/package/@react-ui/hooks) package
provides more than 70 hooks to build custom components. The `@react-ui/hooks`
package is used internally in most other `@mantine/*` packages –
it is required to be installed in your project to use ReactUI components.

## Installation

<InstallScript packages="@react-ui/hooks" />

## Usage

The `@react-ui/hooks` package can be used in any web React application, and state
management hooks (like [use-pagination](/hooks/use-pagination) or [use-queue](/hooks/use-queue))
are also compatible with React Native. The package can be used even if you
do not use ReactUI components or other ReactUI libraries – it is standalone
and has no dependencies except React.
