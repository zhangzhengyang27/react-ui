# ReactUI hooks

[![npm](https://img.shields.io/npm/dm/@react-ui/hooks)](https://www.npmjs.com/package/@react-ui/hooks)

[@react-ui/hooks](https://www.npmjs.com/package/@react-ui/hooks) 包
提供了 70 多个用于构建自定义组件的 Hook。`@react-ui/hooks`
包在大多数其他 `@react-ui/*` 包内部被使用——
要使用 ReactUI 组件，你的项目中必须安装它。

## 安装

<InstallScript packages="@react-ui/hooks" />

## 用法

`@react-ui/hooks` 包可以在任何 Web React 应用中使用，其中状态管理 Hook
（如 [use-pagination](/hooks/use-pagination) 或 [use-queue](/hooks/use-queue)）
也兼容 React Native。即使你不使用 ReactUI 组件或其他 ReactUI 库，
也可以单独使用该包——它是独立的，除了 React 之外没有其他依赖。

使用 [use-move](/hooks/use-move) Hook 创建自定义滑块的示例：
