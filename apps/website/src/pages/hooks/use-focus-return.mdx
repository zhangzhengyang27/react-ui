## 用法

`use-focus-return` Hook 在给定条件满足时自动将焦点返回到上一个聚焦的元素。
例如，它在 [Modal](/core/modal/) 组件中用于在弹窗关闭后恢复焦点。

使用 `Escape` 键关闭弹窗，观察焦点如何在弹窗关闭后返回到按钮：

<Demo data={ModalDemos.usage} demoProps={{ toggle: true }} />

在大多数情况下，你应将此 Hook 与 [use-focus-trap](/hooks/use-focus-trap/) 一起使用。

```tsx
import { useFocusReturn } from '@react-ui/hooks';

useFocusReturn({
  // 焦点陷阱区域是否处于活动状态？
  // 当激活时，Hook 会将 document.activeElement 保存到内部状态
  // 并在焦点陷阱停用时聚焦该元素
  opened: false,

  // 决定是否应自动返回焦点，默认为 true
  shouldReturnFocus: true,
});
```

如果 `shouldReturnFocus` 选项设置为 `false`，你可以调用返回的函数来聚焦最后一个活动元素：

```tsx
import { useFocusReturn } from '@react-ui/hooks';

const returnFocus = useFocusReturn({
  opened: false,
  shouldReturnFocus: false,
});

// ... 稍后
returnFocus();
```

## 类型定义

```tsx
interface UseFocusReturnOptions {
  opened: boolean;
  shouldReturnFocus?: boolean;
}

type UseFocusReturnReturnValue = () => void;

function useFocusReturn(options: UseFocusReturnOptions): UseFocusReturnReturnValue
```

## 导出类型

`UseFocusReturnOptions` 和 `UseFocusReturnReturnValue` 类型从 `@react-ui/hooks` 包导出，
可在应用中导入：

```tsx
import type { UseFocusReturnOptions, UseFocusReturnReturnValue } from '@react-ui/hooks';
```
