## 用法

`use-hotkeys` Hook 接受一个热键和处理函数元组数组作为其第一个参数：

- `hotkey` - 热键字符串，例如 `ctrl+E`、`shift+alt+L`、`mod+S`
- `handler` - 按下给定组合键时调用的事件处理函数
- `options` - 热键处理函数的额外选项对象

<Demo data={UseHotkeysDemos.index} />

第二个参数是应该忽略热键的 HTML 标签列表。
默认情况下，如果焦点在 `input`、`textarea` 和 `select` 元素中，热键事件将被忽略。

```tsx
import { useHotkeys } from '@react-ui/hooks';

function Demo() {
  // 仅在焦点位于 input 和 textarea 元素中时忽略热键事件
  useHotkeys(
    [['ctrl+K', () => console.log('Trigger search')]],
    ['INPUT', 'TEXTAREA']
  );

  // 空数组 – 不忽略任何元素上的热键事件
  useHotkeys([['ctrl+K', () => console.log('Trigger search')]], []);
}
```

## 目标元素

`use-hotkeys` Hook 只能与 document 元素一起工作；如果你需要支持其他元素，则需要创建自己的事件监听器。
为此，`@react-ui/hooks` 包导出了一个 `getHotkeyHandler` 函数，应与 `onKeyDown` 一起使用：

<Demo data={UseHotkeysDemos.usage} />

使用 `getHotkeyHandler`，你还可以使用 `.addEventListener` 将事件添加到任何 DOM 节点：

```tsx
import { getHotkeyHandler } from '@react-ui/hooks';

document.body.addEventListener(
  'keydown',
  getHotkeyHandler([
    ['mod+Enter', () => console.log('Submit')],
    ['mod+S', () => console.log('Save')],
  ])
);
```

## 支持的格式

- `mod+S` – 在 macOS 上检测 `⌘+S`，在 Windows 上检测 `Ctrl+S`
- `ctrl+shift+X` – 处理多个修饰键
- `alt + shift + L` – 可以在热键中使用空白字符
- `ArrowLeft` – 可以使用[此格式](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/key/Key_Values)的特殊键
- `shift + [plus]` – 可以使用 `[plus]` 检测 `+` 键
- `Digit1` 和 `Hotkey1` – 可以使用 MDN 上[定义的物理键分配](https://developer.mozilla.org/en-US/docs/Web/API/UI_Events/Keyboard_event_code_values)。

## 类型

`@react-ui/hooks` 包导出 `HotkeyItemOptions` 和 `HotkeyItem` 类型：

```tsx
interface HotkeyItemOptions {
  preventDefault?: boolean;
  usePhysicalKeys?: boolean;
}

type HotkeyItem = [
  string,
  (event: KeyboardEvent) => void,
  HotkeyItemOptions?,
];
```

`HotkeyItemOptions` 提供 `usePhysicalKeys` 选项以强制使用物理键分配。这对于非 QWERTY 键盘布局很有用。

`HotkeyItem` 类型可用于在 `use-hotkeys` Hook 之外创建热键项：

```tsx
import { HotkeyItem, useHotkeys } from '@react-ui/hooks';

const hotkeys: HotkeyItem[] = [
  [
    'mod+J',
    () => console.log('Toggle color scheme'),
    { preventDefault: false },
  ],
  ['ctrl+K', () => console.log('Trigger search')],
  ['alt+mod+shift+X', () => console.log('Rick roll')],
  [
    'D',
    () => console.log('Triggers when pressing "E" on Dvorak keyboards!'),
    { usePhysicalKeys: true }
  ],
];

useHotkeys(hotkeys);
```

## 类型定义

```tsx
interface HotkeyItemOptions {
  preventDefault?: boolean;
  usePhysicalKeys?: boolean;
}

type HotkeyItem = [string, (event: KeyboardEvent) => void, HotkeyItemOptions?]

function useHotkeys(
  hotkeys: HotkeyItem[],
  tagsToIgnore?: string[],
  triggerOnContentEditable?: boolean
): void;
```

## 导出类型

`HotkeyItemOptions` 和 `HotkeyItem` 类型从 `@react-ui/hooks` 包导出：

```tsx
import type { HotkeyItemOptions, HotkeyItem } from '@react-ui/hooks';
```
