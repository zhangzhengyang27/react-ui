## 类型定义

```tsx
interface UseHoverReturnValue<T extends HTMLElement = any> {
  hovered: boolean;
  ref: React.RefCallback<T | null>;
}

function useHover<T extends HTMLElement = any>(): UseHoverReturnValue<T>
```

## 导出类型

`UseHoverReturnValue` 类型从 `@react-ui/hooks` 包导出：

```tsx
import type { UseHoverReturnValue } from '@react-ui/hooks';
```
