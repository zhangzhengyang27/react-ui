## 用法

`use-previous` Hook 将状态的先前值存储在 ref 中。
它在初始渲染时返回 `undefined`，在重新渲染后返回状态的先前值：

<Demo data={UsePreviousDemos.usage} />

## 类型定义

```tsx
function usePrevious<T>(value: T): T | undefined;
```
