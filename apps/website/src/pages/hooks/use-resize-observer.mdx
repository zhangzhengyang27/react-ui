## API 参考

`use-resize-observer` Hook 返回一个应传递给被观察元素的 `ref` 对象，以及当前元素的内容矩形，
其值由 `ResizeObserver` 回调中的 `entry.contentRect` 返回。
更多信息请参阅 [Resize Observer API](https://developer.mozilla.org/en-US/docs/Web/API/ResizeObserver) 文档。
在第一次渲染（以及 SSR 期间）或未观察任何元素时，所有属性均等于 `0`。

```tsx
import { useResizeObserver } from '@react-ui/hooks';

function Demo() {
  const [ref, rect] = useResizeObserver();
  return <div ref={ref}>已观察</div>;
}
```

如果你只需要订阅 `width` 和 `height`，请参阅 [use-element-size](/hooks/use-element-size/) Hook。

## 类型定义

```tsx
type ObserverRect = Omit<DOMRectReadOnly, 'toJSON'>;

function useResizeObserver<T extends HTMLElement = any>(
  options?: ResizeObserverOptions
): readonly [React.RefCallback<T | null>, ObserverRect];
```
