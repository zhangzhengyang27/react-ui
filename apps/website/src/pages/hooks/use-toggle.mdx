## 用法

`use-toggle` Hook 实现了一种常见的状态模式——它在给定值之间切换状态：

<Demo data={UseToggleDemos.usage} />

## API 参考

该 Hook 接受一个数组作为唯一参数；第一个选项将用作默认值。

该 Hook 返回一个包含状态值和切换函数的数组：

```tsx
import { useToggle } from '@react-ui/hooks';

const [value, toggle] = useToggle(['light', 'dark'] as const);

toggle(); // -> value == 'dark'
toggle(); // -> value == 'light'

// 你可以强制指定一个值；此时状态将设置为给定值
toggle('dark'); // -> value == 'dark'
```

如果你未提供包含选项的数组，`use-toggle` 将使用布尔值，默认值为 `false`：

```tsx
import { useToggle } from '@react-ui/hooks';

const [value, toggle] = useToggle();
// -> value === false
toggle(); // -> value === true
```

## 设置类型

默认情况下，TypeScript 会推断你的类型，但在大多数情况下，最好使用 const 断言来防止类型扩大：

```tsx
import { useToggle } from '@react-ui/hooks';

useToggle(['light', 'dark']); // value 为 string
useToggle(['light', 'dark'] as const); // value 为 'dark' | 'light'
useToggle<'dark' | 'light'>(['light', 'dark']); // 与上面相同
```

## 类型定义

```tsx
type UseToggleAction<T> = (value?: React.SetStateAction<T>) => void;
type UseToggleReturnValue<T> = [T, UseToggleAction<T>];

function useToggle<T = boolean>(options?: T[]): UseToggleReturnValue<T>;
```

## 导出类型

`UseToggleReturnValue` 类型从 `@react-ui/hooks` 包导出：

```tsx
import type { UseToggleReturnValue } from '@react-ui/hooks';
```
