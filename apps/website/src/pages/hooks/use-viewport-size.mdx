## 用法

`use-viewport-size` Hook 返回当前视口的 `width` 和 `height`。它订阅 `resize` 和 `orientationchange` 事件。
在 SSR 期间，该 Hook 返回 `{ width: 0, height: 0 }`：

<Demo data={UseViewportSizeDemos.usage} />

## 类型定义

```tsx
function useViewportSize(): {
  height: number;
  width: number;
};
```
