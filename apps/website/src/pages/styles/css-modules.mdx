# CSS modules

所有 ReactUI 组件都使用 CSS modules 进行样式设置。建议你在项目中也使用 CSS modules，但这不是必需的——ReactUI 组件与任何第三方样式解决方案和原生 CSS 完全兼容。

## 用法

所有主流框架和构建工具都原生支持 CSS modules。通常，你只需要创建一个 `*.module.css` 文件：

```css
/* Button.module.css */
.button {
  color: red;
}
```

然后在你的组件中导入它：

```tsx
import classes from './Button.module.css';

function Demo() {
  return (
    <button className={classes.button} type="button">
      Button
    </button>
  );
}
```

## CSS modules 的工作原理

当你创建一个 `*.module.css` 文件时，你的构建工具会为文件中的每个 class 生成一个唯一的 class 名称。例如，当你在 `.js`/`.ts` 文件中导入以下文件时：

```css
/* Button.module.css */
.button {
  color: red;
}

.text {
  color: blue;
}
```

你会得到一个包含唯一 class 名称的对象：

```tsx
import classes from './Button.module.css';

console.log(classes);
// -> 作用域 class 名称的对象：key 是 class 名称，value 是生成的唯一 class 名称
// { button: 'button-Xh3s7ER', text: 'text-js65s3Se' }
// 注意，生成的 class 名称可能因构建工具而异
```

使用 CSS modules，你无需担心 class 名称冲突。你可以使用任何你想要的 class 名称。

## 引用全局 class 名称

要在 CSS Modules 中引用全局 class 名称，你可以使用 `:global` 选择器：

```scss
.test {
  & :global(.global-class-name) {
    color: red;
  }
}
```

上面的代码将编译为以下 CSS：

```css
.m-dj3w33 .global-class-name {
  color: red;
}
```

## 为 ReactUI 组件添加样式

你可以使用 `className` prop 为大多数 ReactUI 组件添加样式——这与使用常规 HTML 元素的方式相同。要将属性设置为你的[主题](/theming/theme-object)值，你可以使用 [ReactUI CSS 变量](/styles/css-variables)：

## 不使用 CSS modules 样式化 ReactUI 组件

所有 ReactUI 组件与任何第三方样式解决方案和原生 CSS 完全兼容。使用第三方库应用样式有两种主要策略：

- `className`、`classNames`、`style` 和 `styles` props
- 使用静态选择器，例如 `.mantine-Text-root`

使用实用工具 CSS 库应用样式的示例：

```tsx
import { TextInput } from '@react-ui/ui';

function Demo() {
  return (
    <TextInput
      classNames={{
        root: 'mt-4',
        input: 'bg-red-500 text-white',
      }}
    />
  );
}
```

使用全局 CSS 应用样式的示例：

```css
/* styles.css */

/* 注意，这些样式没有作用域，
   会应用到所有 TextInput 组件 */
.mantine-TextInput-root {
  margin-top: 0.8rem;
}

.mantine-TextInput-input {
  background-color: var(--mantine-color-red-filled);
  color: var(--mantine-color-white);
}
```

你可以组合这两种方法以获得所需的结果。例如，`@emotion/styled` 和 `styled-components` 包会将 `className` prop 传递给给定组件，你可以使用静态选择器来样式化内部元素：

```tsx
import styled from '@emotion/styled';
import { Slider } from '@react-ui/ui';

const StyledSlider = styled(Slider)`
  & .mantine-Slider-bar {
    background-color: var(--mantine-color-pink-5);
  }

  & .mantine-Slider-thumb {
    border-color: var(--mantine-color-pink-5);
    background-color: white;
    width: 1.5rem;
    height: 1.5rem;
  }
`;

function Demo() {
  return <StyledSlider defaultValue={40} />;
}
```

> **优先考虑使用 CSS modules**
>
> CSS modules 是样式化 ReactUI 组件的推荐方式。在选择其他样式解决方案之前，请确保 CSS modules 不满足你的需求。
> 其他解决方案存在限制，例如：
>
> - 使用基于实用工具的 CSS 库时，很难基于 [data-* 属性](/styles/data-attributes) 自定义样式
> - 如果组件使用 [Portal](/core/portal)，则使用 styled-components 和其他类似库无法通过静态选择器样式化 ReactUI 组件的内部元素，因为某些元素会渲染在组件根节点之外，内部元素不属于组件树的一部分
