# 配合 Emotion 使用

在 7.0 版本之前，ReactUI 使用 [Emotion](https://emotion.sh/) 作为样式解决方案。
它在 7.0 版本中被 [CSS modules](/styles/css-modules/) 取代，但如果你更喜欢 Emotion，
仍然可以将其与 ReactUI 一起使用。

注意，`createStyles` 函数、`sx` 和 `styles` props 的工作方式与旧版本中的同名功能不同。
如果你计划从旧版本升级，请参考 [GitHub releases](https://github.com/react-ui-org/react-ui/releases) 中的迁移信息。

`@react-ui/emotion` 包兼容 `@react-ui/ui` 7.9.0 及更高版本。在安装之前，
请确保你使用的所有 `@react-ui/*` 包都是最新版本。

## 注意事项与支持

[Emotion](https://emotion.sh/) 是一个运行时 CSS-in-JS 库——样式在运行时生成并注入到 DOM 中。
这种方式有一些限制：

- **服务端渲染支持有限** – 现代框架（如使用 app router 的 Next.js）不完全支持 Emotion，或需要额外配置。
- **运行时开销** – 样式在运行时生成和注入，在包含大量组件的页面上可能导致性能问题。
- **额外的打包体积** – 你的打包文件将包含 `@emotion/react`（21.2kB minified）、
  `@react-ui/emotion`（~2kb minified）以及你在组件中使用的所有样式。

`@react-ui/emotion` 包可用于以下框架：

- **Vite** 和 **CRA**，基础配置即可
- **Next.js pages router**，包提供了额外的服务端渲染配置
- **Next.js app router**，Emotion 提供了额外的服务端渲染配置
- 任何其他不需要服务端渲染的框架，基础配置即可

以下框架没有官方支持（该包可能可以使用，但未经测试且不提供文档）：

- **React Router**
- **Gatsby**
- **Redwood**
- 任何其他具有服务端渲染的框架

注意，Emotion 不推荐用于新项目。如果你要用 ReactUI 开始一个新项目，
建议改用 [CSS modules](/styles/css-modules/)。

## 配合 Vite 使用

[查看完整配置的示例仓库](https://github.com/react-ui-org/vite-min-template/tree/emotion)

安装依赖：

<InstallScript packages="@react-ui/emotion @emotion/react @emotion/cache @emotion/serialize @emotion/utils" />

在 `src` 目录下创建 `emotion.d.ts` 文件，为 `sx` 和 `styles` props 添加类型支持：

```tsx
import '@react-ui/ui';

import type { EmotionStyles, EmotionSx } from '@react-ui/emotion';

declare module '@react-ui/ui' {
  export interface BoxProps {
    sx?: EmotionSx;
    styles?: EmotionStyles;
  }
}
```

用 `UIEmotionProvider` 包裹你的应用，并将 `emotionTransform` 添加到 `UIProvider`：

```tsx
import '@react-ui/ui/styles.css';

import { UIProvider } from '@react-ui/ui';
import {
  emotionTransform,
  UIEmotionProvider,
} from '@react-ui/emotion';

export default function App() {
  return (
    <UIProvider stylesTransform={emotionTransform}>
      <UIEmotionProvider>应用</UIEmotionProvider>
    </UIProvider>
  );
}
```

完成！现在你可以在你的应用中使用 `sx`、`styles` props 和 `createStyles`：

```tsx
import { Box } from '@react-ui/ui';

function Demo() {
  return (
    <Box
      sx={(theme, u) => ({
        padding: 40,

        [u.light]: {
          backgroundColor: theme.colors.blue[0],
          color: theme.colors.blue[9],

          '&:hover': {
            backgroundColor: theme.colors.blue[1],
          },
        },
      })}
    >
      Box with emotion sx prop
    </Box>
  );
}
```

## 配合 Next.js pages router 使用

[查看完整配置的示例仓库](https://github.com/react-ui-org/next-pages-min-template/tree/emotion)

安装依赖：

<InstallScript packages="@react-ui/emotion @emotion/react @emotion/cache @emotion/serialize @emotion/utils @emotion/server" />

创建 `emotion` 文件夹，并添加 `cache.ts` 和 `emotion.d.ts` 文件。

`cache.ts` 文件：

```tsx
import createCache from '@emotion/cache';

export const emotionCache = createCache({ key: 'css' });
```

`emotion.d.ts` 文件：

```tsx
import '@react-ui/ui';

import type { EmotionStyles, EmotionSx } from '@react-ui/emotion';

declare module '@react-ui/ui' {
  export interface BoxProps {
    sx?: EmotionSx;
    styles?: EmotionStyles;
  }
}
```

将以下内容添加到你的 `pages/_document.tsx` 文件中：

```tsx
import NextDocument, {
  Head,
  Html,
  Main,
  NextScript,
} from 'next/document';
import createEmotionServer from '@emotion/server/create-instance';
import { ColorSchemeScript } from '@react-ui/ui';
import { createGetInitialProps } from '@react-ui/emotion';
// Import cache created in the previous step
import { emotionCache } from '../emotion/cache';

export default function Document() {
  return (
    <Html lang="en">
      <Head>
        <ColorSchemeScript />
      </Head>
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  );
}

const stylesServer = createEmotionServer(emotionCache);

Document.getInitialProps = createGetInitialProps(
  NextDocument,
  stylesServer
);
```

将 `UIEmotionProvider` 和 `emotionTransform` 添加到你的 `pages/_app.tsx` 文件中：

```tsx
import '@react-ui/ui/styles.css';

import Head from 'next/head';
import { UIProvider } from '@react-ui/ui';
import {
  emotionTransform,
  UIEmotionProvider,
} from '@react-ui/emotion';
import { emotionCache } from '../emotion/cache';

export default function App({ Component, pageProps }: any) {
  return (
    <UIEmotionProvider cache={emotionCache}>
      <UIProvider stylesTransform={emotionTransform}>
        <Head>
          <title>ReactUI 模板</title>
          <meta
            name="viewport"
            content="minimum-scale=1, initial-scale=1, width=device-width, user-scalable=no"
          />
          <link rel="shortcut icon" href="/favicon.svg" />
        </Head>
        <Component {...pageProps} />
      </UIProvider>
    </UIEmotionProvider>
  );
}
```

完成！现在你可以在你的应用中使用 `sx`、`styles` props 和 `createStyles`：

```tsx
import { Box } from '@react-ui/ui';

function Demo() {
  return (
    <Box
      sx={(theme, u) => ({
        padding: 40,

        [u.light]: {
          backgroundColor: theme.colors.blue[0],
          color: theme.colors.blue[9],

          '&:hover': {
            backgroundColor: theme.colors.blue[1],
          },
        },
      })}
    >
      Box with emotion sx prop
    </Box>
  );
}
```

## 配合 Next.js app router 使用

[查看完整配置的示例仓库](https://github.com/react-ui-org/next-app-min-template/tree/emotion)

安装依赖：

<InstallScript packages="@react-ui/emotion @emotion/react @emotion/cache @emotion/serialize @emotion/utils @emotion/server" />

创建 `app/emotion.d.ts` 文件，内容如下：

```tsx
import '@react-ui/ui';

import type { EmotionStyles, EmotionSx } from '@react-ui/emotion';

declare module '@react-ui/ui' {
  export interface BoxProps {
    sx?: EmotionSx;
    styles?: EmotionStyles;
  }
}
```

创建 `app/EmotionRootStyleRegistry.tsx` 文件，内容如下：

```tsx
'use client';

import { useState } from 'react';
import { useServerInsertedHTML } from 'next/navigation';
import createCache from '@emotion/cache';
import { CacheProvider } from '@emotion/react';

export function RootStyleRegistry({
  children,
}: {
  children: React.ReactNode;
}) {
  const [{ cache, flush }] = useState(() => {
    const cache = createCache({ key: 'my' });
    cache.compat = true;
    const prevInsert = cache.insert;
    let inserted: string[] = [];
    cache.insert = (...args) => {
      const serialized = args[1];
      if (cache.inserted[serialized.name] === undefined) {
        inserted.push(serialized.name);
      }
      return prevInsert(...args);
    };
    const flush = () => {
      const prevInserted = inserted;
      inserted = [];
      return prevInserted;
    };
    return { cache, flush };
  });

  useServerInsertedHTML(() => {
    const names = flush();
    if (names.length === 0) return null;
    let styles = '';
    for (const name of names) {
      styles += cache.inserted[name];
    }
    return (
      <style
        data-emotion={`${cache.key} ${names.join(' ')}`}
        dangerouslySetInnerHTML={{
          __html: styles,
        }}
      />
    );
  });

  return <CacheProvider value={cache}>{children}</CacheProvider>;
}
```

将 `RootStyleRegistry`、`UIEmotionProvider` 和 `emotionTransform` 添加到你的 `app/layout.tsx` 中。
它看起来应该像这样：

```tsx
import '@react-ui/ui/styles.css';

import { ColorSchemeScript, UIProvider } from '@react-ui/ui';
import {
  emotionTransform,
  UIEmotionProvider,
} from '@react-ui/emotion';
import { RootStyleRegistry } from './EmotionRootStyleRegistry';

export const metadata = {
  title: 'ReactUI Next.js template',
  description: 'I am using ReactUI with Next.js!',
};

export default function RootLayout({ children }: { children: any }) {
  return (
    <html lang="en">
      <head>
        <ColorSchemeScript />
        <link rel="shortcut icon" href="/favicon.svg" />
        <meta
          name="viewport"
          content="minimum-scale=1, initial-scale=1, width=device-width, user-scalable=no"
        />
      </head>
      <body>
        <RootStyleRegistry>
          <UIEmotionProvider>
            <UIProvider stylesTransform={emotionTransform}>
              {children}
            </UIProvider>
          </UIEmotionProvider>
        </RootStyleRegistry>
      </body>
    </html>
  );
}
```

完成！现在你可以在你的应用中使用 `sx`、`styles` props 和 `createStyles`。
注意，大多数使用 `sx`、`styles` 或 `createStyles` 的组件都需要 `'use client'`：

```tsx
'use client';

import { Box } from '@react-ui/ui';

export default function HomePage() {
  return (
    <Box
      sx={(theme, u) => ({
        padding: 40,

        [u.light]: {
          backgroundColor: theme.colors.blue[0],
          color: theme.colors.blue[9],

          '&:hover': {
            backgroundColor: theme.colors.blue[1],
          },
        },
      })}
    >
      Box with emotion sx prop
    </Box>
  );
}
```

## sx prop

完成上述配置后，你可以在所有 ReactUI 组件中使用 `sx` prop。
`sx` prop 允许为组件的根元素添加样式。
它接受一个样式对象，或一个接收 theme 和 utilities 并返回样式对象的函数：

```tsx
import { Box, Button } from '@react-ui/ui';

function Demo() {
  return (
    <>
      <Box
        sx={{
          padding: 40,
          '&:hover': { padding: 80 },
        }}
      >
        Box with object sx
      </Box>

      <Button
        sx={(theme, u) => ({
          padding: 10,

          [u.light]: {
            backgroundColor: theme.colors.blue[0],
            color: theme.colors.blue[9],
            '&:hover': {
              backgroundColor: theme.colors.blue[1],
            },
          },

          [u.dark]: {
            backgroundColor: theme.colors.blue[9],
            color: theme.colors.blue[0],
            '&:hover': {
              backgroundColor: theme.colors.blue[8],
            },
          },
        })}
      >
        Button with function sx
      </Button>
    </>
  );
}
```

### mergeSx 函数

你可以使用 `mergeSx` 函数将多个 `sx` props 合并为一个。这在将传递给自定义组件的 `sx` prop
与其自身的 `sx` 合并时非常有用，例如：

```tsx
import { Box } from '@react-ui/ui'
import { EmotionSx, mergeSx } from '@react-ui/emotion'

interface MyCustomBoxProps {
  sx?: EmotionSx
}

function MyCustomBox({ sx }: MyCustomBoxProps) {
  return (
    <Box sx={mergeSx(theme => ({ ... }), sx)}>...</Box>
  )
}

function App() {
  return (
    <MyCustomBox sx={(theme) => ({ ... })} />
  )
}
```


## styles prop

`styles` prop 的工作方式与 `sx` prop 类似，但它允许为 Styles API 表格中指定的组件所有嵌套元素添加样式。
`styles` prop 接受一个样式对象的对象，或一个接收 theme、组件 props 和 utilities 并返回样式对象的函数：

```tsx
import { Button } from '@react-ui/ui';

function Demo() {
  return (
    <Button
      color="red"
      styles={(theme, { color }, u) => ({
        root: {
          padding: 10,
          backgroundColor: theme.colors[color || 'blue'][7],
          color: theme.white,

          '&:hover': {
            backgroundColor: theme.colors[color || 'blue'][8],
          },
        },
        label: {
          [u.light]: {
            border: `1px solid ${theme.black}`,
          },
          [u.dark]: {
            border: `1px solid ${theme.white}`,
          },
        },
      })}
    >
      Button with styles prop
    </Button>
  );
}
```

## theme 中的 styles

你可以使用 [Styles API](/styles/styles-api/) 和 `styles` prop 配合 Emotion 为 ReactUI 组件添加样式。
注意，为了避免类型冲突，你不应使用 `Component.extend` 方法，而是直接传递组件配置对象。

```tsx
import { createTheme, UITheme, TextProps } from '@react-ui/ui';
import { EmotionHelpers } from '@react-ui/emotion';

export const theme = createTheme({
  components: {
    Text: {
      styles: (
        theme: UITheme,
        _props: TextProps,
        u: EmotionHelpers
      ) => ({
        root: {
          [u.light]: {
            color: theme.colors.blue[7],
          },
        },
      }),
    },
  },
});
```

## createStyles

`createStyles` 函数接受一个使用 [Emotion](https://emotion.sh/) 生成样式的函数。
该函数接收 3 个参数，将在下面的 demo 中详细介绍：

- `theme` – [ReactUI theme 对象](/theming/theme-object)
- `params` – 包含额外参数的对象，可以通过 `useStyles` hook 传递给函数
- `u` - 用于生成选择器的 utilities 对象

## 工具函数

`sx`、`styles` 和 `createStyles` 的回调函数会接收一个 `u` 对象，其中包含用于生成选择器的 utilities。
`u` 对象包含以下属性：

```tsx
const u = {
  light: '[data-ui-color-scheme="light"] &',
  dark: '[data-ui-color-scheme="dark"] &',
  rtl: '[dir="rtl"] &',
  ltr: '[dir="ltr"] &',
  notRtl: '[dir="ltr"] &',
  notLtr: '[dir="rtl"] &',
  ref: getStylesRef,
  smallerThan: (breakpoint: UIBreakpoint | number) =>
    `@media (max-width: ${em(getBreakpointValue(theme, breakpoint) - 0.1)})`,
  largerThan: (breakpoint: UIBreakpoint | number) =>
    `@media (min-width: ${em(getBreakpointValue(theme, breakpoint))})`,
};
```

除 `ref` 外，所有 utilities 都可以在样式对象中作为选择器使用：

```tsx
const styles = {
  root: {
    [u.dark]: { color: 'white' },
    [u.rtl]: { padding: 10 },
    [u.smallerThan('md')]: { lineHeight: 20 },
  },
};
```
