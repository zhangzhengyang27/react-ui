# ReactUI styles

本指南解释如何在应用中导入 `@mantine/*` 包的样式，以及如果你无法控制应用中样式表的顺序，如何使用 [CSS layers](https://developer.mozilla.org/en-US/docs/Web/CSS/@layer) 覆盖它们。

## ReactUI 组件样式

所有 ReactUI 组件都是使用 CSS modules 构建的，但所有样式在发布到 npm 之前都已打包。要包含这些样式，你需要在应用中导入 `@mantine/{package}/styles.css` 文件。以 `@react-ui/ui` 包为例：

```tsx
import '@react-ui/ui/styles.css';
```

通过添加此导入，你的应用中将包含所有 `@react-ui/ui` 组件的样式。

## 按组件导入样式

如果你想减小 CSS 包大小，可以按组件导入样式。注意，某些组件有依赖项。例如，[Button](/core/button) 组件内部使用 [UnstyledButton](/core/unstyled-button) 组件，因此你需要同时导入这两个组件的样式。你可以在[此页面](/styles/css-files-list)找到 `@react-ui/ui` 包导出的所有样式列表和附加说明。

```tsx
import '@react-ui/ui/styles/UnstyledButton.css';
import '@react-ui/ui/styles/Button.css';
```

注意，单个组件样式仅适用于 `@react-ui/ui` 包。其他包具有最小样式，可以使用 `@mantine/{package}/styles.css` 导入。

## 样式导入顺序

保持正确的样式导入顺序很重要。`@react-ui/ui` 包的样式必须始终在其他 ReactUI 包样式之前导入：

```tsx
// ✅ 正确顺序
import '@react-ui/ui/styles.css';
import '@react-ui/ui/styles.css';
// ❌ 错误顺序
import '@react-ui/ui/styles.css';
import '@react-ui/ui/styles.css';
```

你的应用样式必须始终在所有 `@mantine/*` 包样式之后导入：

```tsx
// ✅ 正确顺序 - 你的样式将覆盖 ReactUI 样式
import '@react-ui/ui/styles.css';
import '@react-ui/ui/styles.css';
import classes from './Demo.module.css';

// ❌ 错误顺序 – ReactUI 样式将覆盖你的样式
import classes from './Demo.module.css';
import '@react-ui/ui/styles.css';
import '@react-ui/ui/styles.css';
```

## CSS 层

某些打包工具和框架不允许你控制应用中样式表的顺序。例如，Next.js 不保证[样式导入顺序](https://github.com/vercel/next.js/issues/16630)。在这种情况下，你可以使用 [CSS layers](https://developer.mozilla.org/en-US/docs/Web/CSS/@layer) 来确保你的样式始终覆盖 ReactUI 样式。

所有导出样式的 `@mantine/*` 包都有一个额外的文件，其中所有样式都包裹在 `@layer mantine` 指令中。

```tsx
import '@react-ui/ui/styles.layer.css';
import '@react-ui/ui/styles.layer.css';

// ... 其他样式
```

这些文件包含与 `styles.css` 文件相同的样式，但包裹在 `@layer mantine` 指令中。请确保不要在应用中同时导入 `styles.css` 和 `styles.layer.css` 文件。

```tsx
// ❌ 不要同时导入 styles.css 和 styles.layer.css
import '@react-ui/ui/styles.css';
import '@react-ui/ui/styles.layer.css';
```

与包样式类似，你可以导入带有 `@layer mantine` 指令的单个组件样式：

```tsx
import '@react-ui/ui/styles/UnstyledButton.layer.css';
import '@react-ui/ui/styles/Button.layer.css';

// ... 其他样式
```

## CSS layers 的工作原理

层内的 CSS 规则会被组合在一起，并在没有层的规则之前应用。这意味着即使你无法控制样式导入顺序，仍然可以使用常规样式覆盖 ReactUI 样式。

```tsx
// ✅ 如果你的样式没有包裹在 @layer 指令中，
// 它们将在 ReactUI 样式之后应用
import classes from './Demo.module.css';

import '@react-ui/ui/styles.layer.css';
```

如果你想将 ReactUI 组件与其他也提供样式的库结合使用，CSS layers 也很有用。你可以使用 `@layer` 指令来控制样式顺序：

```scss
@layer base, mantine, components;
```

在此示例中，ReactUI 样式将优先于其他库的 `base` 样式，但其他库的 `components` 样式将优先于 ReactUI 组件样式。

截至 2026 年 1 月，CSS layers 已在所有现代浏览器中得到支持，并拥有 [95% 的浏览器支持率](https://caniuse.com/css-cascade-layers)。

## 从 CDN 加载样式

你也可以从 unpkg CDN 加载 ReactUI 样式。注意，在这种情况下，建议在你的 `package.json` 和 CDN 链接中都指定 `@mantine/*` 包的确切版本。

```html
<!-- 常规样式 -->
<link
  rel="stylesheet"
  href="https://unpkg.com/@react-ui/ui@7.4.2/styles.css"
/>

<!-- 带 @layer 指令的样式 -->
<link
  rel="stylesheet"
  href="https://unpkg.com/@react-ui/ui@7.4.2/styles.layer.css"
/>
```

unpkg CDN 上的样式适用于所有导出样式的 ReactUI 包。
