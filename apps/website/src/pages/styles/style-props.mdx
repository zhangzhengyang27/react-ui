# Style props

通过 style props，你可以为任何 ReactUI 组件添加内联样式。
Style props 会作用于组件的**根**元素。如果你需要为嵌套元素设置样式，
请改用 [Styles API](/styles/styles-api/)。

```tsx
import { Box } from '@react-ui/ui';

function Demo() {
  return (
    <Box mx="auto" maw={400} c="blue.6" bg="#fff">
      Your component
    </Box>
  );
}
```

## 主题值

某些 style props 可以引用主题中的值。例如，当你设置 `xs`、`sm`、`md`、`lg`、`xl` 时，`mt` 会使用 `theme.spacing` 的值：

```tsx
import { Box } from '@react-ui/ui';

function Demo() {
  return (
    <>
      {/* margin-top: theme.spacing.xs */}
      <Box mt="xs" />

      {/* margin-top: theme.spacing.md * -1 */}
      <Box mt="-md" />

      {/* margin-top: auto */}
      <Box mt="auto" />

      {/* margin-top: 1rem */}
      <Box mt={16} />

      {/* margin-top: 5rem */}
      <Box mt="5rem" />
    </>
  );
}
```

在 `c`、`bd` 和 `bg` 属性中，你可以引用 `theme.colors` 中的颜色：

```tsx
import { Box } from '@react-ui/ui';

function Demo() {
  return (
    <>
      {/* color: theme.colors.blue[theme.primaryShade] */}
      <Box c="blue" />

      {/* background: theme.colors.orange[1] */}
      <Box bg="orange.1" />

      {/* border: 1px solid theme.colors.red[6] */}
      <Box bd="1px solid red.6" />

      {/* color: 如果 colorScheme 为 dark，则使用 `var(--mantine-color-dark-2)`，
      如果 color scheme 为 light，则使用 `var(--mantine-color-gray-6)` */}
      <Box c="dimmed" />

      {/* color: 如果 colorScheme 为 dark，则使用 `var(--mantine-color-white)`，
      如果 color scheme 为 light，则使用 `var(--mantine-color-black)` */}
      <Box c="bright" />

      {/* background: #EDFEFF */}
      <Box bg="#EDFEFF" />

      {/* background: rgba(0, 34, 45, 0.6) */}
      <Box bg="rgba(0, 34, 45, 0.6)" />
    </>
  );
}
```

## 响应式样式

你可以使用对象语法为 style props 添加响应式样式。
注意，响应式 style props 的性能低于普通 style props（参见 [样式性能](/styles/styles-performance)）。
不建议在大量元素列表中使用它们。

<Demo data={StylesDemos.responsiveStyleProps} />

响应式值的计算规则如下：

- 当没有任何断点值匹配时，使用 `base` 值
- 当视口宽度大于 [theme.breakpoints](/styles/responsive/) 中对应断点的值时，使用 `xs`、`sm`、`md`、`lg`、`xl` 值

```tsx
import { Box } from '@react-ui/ui';

function Demo() {
  return <Box w={{ base: 320, sm: 480, lg: 640 }} />;
}
```

此时元素将拥有以下样式：

```css
/* 基础样式会添加到元素上，然后被响应式值覆盖 */
.element {
  width: 20rem;
}

/* 48em 是默认的 theme.breakpoints.sm */
@media (min-width: 48em) {
  .element {
    width: 30rem;
  }
}

/* 75em 是默认的 theme.breakpoints.lg */
@media (min-width: 75em) {
  .element {
    width: 40rem;
  }
}
```
