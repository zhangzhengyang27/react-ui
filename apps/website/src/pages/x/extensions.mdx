# ReactUI extensions

Extensions are packages that provide additional functionality like
new components, hooks, or other features. They are built on top of
`@react-ui/hooks` and `@react-ui/ui` packages.

## Official extensions

Official extensions are built by the maintainers of ReactUI. These extensions have the `@mantine/` scope
in their package names, for example `@react-ui/ui` or `@react-ui/ui`.

Official extensions list:

- [@react-ui/ui](/dates/getting-started) – date and time pickers, calendars, other date-related components
- [@react-ui/ui](/charts/getting-started) – charts and data visualization components based on recharts
- [@react-ui/ui](/x/notifications) – notifications system
- [@react-ui/ui](/x/code-highlight) – code highlighting component used on ReactUI websites
- [@react-ui/ui](/x/spotlight) – control center (`Ctrl + K` search bar), can be used for search
- [@react-ui/ui](/x/carousel) – carousel component based on embla-carousel
- [@react-ui/ui](/x/dropzone) – captures files with drag and drop, based on react-dropzone
- [@react-ui/ui](/x/modals) – modals manager
- [@react-ui/ui](/x/tiptap) – rich text editor based on tiptap
- [@react-ui/ui](/x/nprogress) – navigation progress component

## Create your own extension

You are welcome to create your own extension and share it with the community
in the list above. To submit a new extension to be featured on this page:

- Create and publish an extension on npm. You can choose any name for your package, for example `reactui-oklch-color-picker` or `@xiaoye/reactui-emoji-picker`.
- If you are not sure how to get started with extension development, use the [extension template](https://github.com/xiaoye/react-ui-extension-template). It provides a full development environment with tests, documentation, and examples.
- Submit a pull request to the [ReactUI repository](https://github.com/xiaoye/react-ui) with a link to your extension and a short description to be featured on this page.
