## 安装

<InstallScript packages="@react-ui/ui" />

安装完成后，在应用根目录导入包样式：

```tsx
import '@react-ui/ui/styles.css';
// ‼️ notifications 样式必须在核心包样式之后导入
import '@react-ui/ui/styles.css';
```

在应用中的任意位置添加 `Notifications` 组件。注意：

- 必须在 [UIProvider](/theming/ui-provider/) 内部渲染 `Notifications` 组件
- 你不需要用 `Notifications` 组件包裹整个应用——它不是 provider，而是一个普通组件
- 你不应该渲染多个 `Notifications` 组件——如果这样做，你的通知会被重复显示

```tsx
import { UIProvider } from '@react-ui/ui';
import { Notifications } from '@react-ui/ui';

function Demo() {
  return (
    <UIProvider>
      <Notifications />
      {/* 你的应用内容 */}
    </UIProvider>
  );
}
```

全部完成！你现在可以使用通知系统的所有功能。

## 函数

`@react-ui/ui` 包导出一个 `notifications` 对象，包含以下函数：

- `notifications.show` – 将给定的通知添加到通知列表或队列中，具体取决于当前状态和 `limit`
- `notifications.hide` – 从通知状态和队列中移除具有给定 `id` 的通知
- `notifications.update` – 更新之前已添加到状态或队列中的通知
- `notifications.updateState` – 执行一个回调，该回调接收当前通知状态和队列作为参数，并用返回值更新状态
- `notifications.clean` – 从通知状态和队列中移除所有通知
- `notifications.cleanQueue` – 从队列中移除所有通知

所有函数都可以从 `@react-ui/ui` 包导入，并可在应用的任何部分使用：

```tsx
import { notifications } from '@react-ui/ui';
```

你也可以单独导入这些函数：

```tsx
// 别名函数
import {
  cleanNotifications, // notifications.clean
  cleanNotificationsQueue, // notifications.cleanQueue
  hideNotification, // notifications.hide
  showNotification, // notifications.show
  updateNotification, // notifications.update
  updateNotificationsState, // notifications.updateState
} from '@react-ui/ui';
```

## 通知属性

`notifications.show` 和 `notifications.update` 函数可以用一个具有以下属性的对象调用：

- `id` – 通知 id，用于更新和移除通知；默认情况下，`id` 随机生成
- `position` – 通知位置；默认情况下，使用 `Notifications` 组件的 `position` 属性值
- `withBorder` – 决定通知是否显示边框
- `withCloseButton` – 决定关闭按钮是否可见
- `allowClose` – 决定通知是否可以通过关闭按钮、拖动或水平滑动手势关闭，默认为 `true`
- `onClose` – 通知卸载时调用
- `onOpen` – 通知挂载时调用
- `autoClose` – 定义通知自动关闭前的超时时间（毫秒）；使用 `false` 禁用自动关闭
- `priority` – 当活动通知数量超过 `limit` 时使用的显示优先级；数字越大越优先显示，默认为 `0`
- `message` – 必需的通知正文
- `color, icon, title, radius, className, style, loading` – 传递给 [Notification](/core/notification/) 组件的属性

除 `message` 外，所有属性都是可选的。

```tsx
import { XIcon } from '@phosphor-icons/react';
import { notifications } from '@react-ui/ui';

// 最低要求 – message 对所有通知都是必需的
notifications.show({ message: 'Hello' });

// 最常用的通知属性
notifications.show({
  id: 'hello-there',
  position: 'bottom-center',
  withCloseButton: true,
  allowClose: true,
  onClose: () => console.log('unmounted'),
  onOpen: () => console.log('mounted'),
  autoClose: 5000,
  title: "You've been compromised",
  message: 'Leave the building immediately',
  color: 'red',
  icon: <XIcon />,
  className: 'my-notification-class',
  style: { backgroundColor: 'red' },
  loading: false,
});
```

## 关闭交互

可以通过左右拖动通知，或在悬停时水平滚动滑动手势来关闭通知。

在 `Notifications` 上使用 `allowDragDismiss` 和 `allowScrollDismiss` 来禁用任一交互：

```tsx
import { Notifications } from '@react-ui/ui';

function Demo() {
  return <Notifications allowDragDismiss={false} allowScrollDismiss={false} />;
}
```

要使特定通知不可关闭，请在 `notifications.show` 或 `notifications.update` 中设置 `allowClose: false`。这会隐藏关闭按钮，并禁用该通知的拖动/滚动关闭。

## 通知容器位置

你可以在 `notifications.show` 函数中定义通知位置。可能的 `position` 值：

- `top-left`
- `top-right`
- `top-center`
- `bottom-left`
- `bottom-right`
- `bottom-center`

`position` 也可以在 `Notifications` 组件上定义。在以下示例中，如果 `notifications.show` 函数中未定义 `position`，通知将显示在屏幕右上角：

```tsx
import { Notifications } from '@react-ui/ui';

function Demo() {
  return <Notifications position="top-right" zIndex={1000} />;
}
```

## 限制与队列

你可以通过在 `Notifications` 上设置 `limit` 属性来限制同时显示的最大通知数量：

```tsx
import { Notifications } from '@react-ui/ui';

function Demo() {
  return <Notifications limit={5} />;
}
```

达到 `limit` 后添加的所有通知都会进入队列，并在当前状态中的通知隐藏时显示。

## 优先级

默认情况下，通知按照插入顺序（FIFO）分配到可见状态和队列：前 `limit` 个通知可见，其余在队列中等待。在 `notifications.show` 或 `notifications.update` 中设置 `priority` 属性，以控制当活动通知数量超过 `limit` 时，哪些通知占据可见位置。

- `priority` 较高的通知会在 `priority` 较低的通知之前显示。
- `priority` 相等的通知保持插入顺序（FIFO）。
- `priority` 默认为 `0`，因此未设置优先级的通知行为与之前完全相同。
- 在可见集合中，优先级较高的通知会先渲染。

当可见状态已达到 `limit` 时添加高优先级通知，它会占据一个可见位置，而优先级最低的可见通知会被移入队列——即使它已经在显示中。优先级对每个位置独立应用。

注意，从可见状态移回队列的通知会被卸载，并在重新返回可见位置时再次挂载，因此它的 `onOpen` 回调每次变为可见时都会运行。

在以下示例中，`Notifications` 组件使用 `limit={1}`。先显示一个低优先级通知，然后显示一个高优先级通知：高优先级通知会替换低优先级通知，低优先级通知被移入队列，并在高优先级通知关闭后再次显示。

## 自动关闭

你可以通过 `Notifications` 配置自动关闭超时时间：

```tsx
import { Notifications } from '@react-ui/ui';

// 所有通知将在 4000ms 后自动关闭
function Demo() {
  return <Notifications autoClose={4000} />;
}
```

或在 `notifications.show`/`notifications.update` 函数中针对每个通知进行配置：

```tsx
import { notifications } from '@react-ui/ui';

notifications.show({
  message: 'I will close in 500ms seconds',
  autoClose: 500,
});

notifications.update({
  id: 'hello',
  message: 'I will never close',
  autoClose: false,
});
```

`notifications.show` 和 `notifications.update` 函数的 `autoClose` 属性优先级更高。

## 悬停时暂停自动关闭

默认情况下，悬停在任意通知上会暂停所有可见通知的自动关闭计时器。你可以通过 `pauseResetOnHover` 属性更改此行为：

- `pauseResetOnHover="all"`（默认）– 悬停任意通知时暂停所有通知的自动关闭
- `pauseResetOnHover="notification"` – 仅暂停被悬停通知的自动关闭

```tsx
import { Notifications } from '@react-ui/ui';

function Demo() {
  return <Notifications pauseResetOnHover="notification" />;
}
```

## 订阅通知状态
