# @react-ui/charts

[![npm](https://img.shields.io/npm/dm/@react-ui/charts)](https://www.npmjs.com/package/@react-ui/charts)

Charts components built with recharts and Mantine

[View documentation](https://mantine.dev/)

## Installation

```bash
# With yarn
yarn add @react-ui/charts @react-ui/ui @react-ui/hooks recharts

# With npm
npm install @react-ui/charts @react-ui/ui @react-ui/hooks recharts
```
