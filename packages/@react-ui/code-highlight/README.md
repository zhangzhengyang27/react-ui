# UI code highlight

[![npm](https://img.shields.io/npm/dm/@react-ui/code-highlight)](https://www.npmjs.com/package/@react-ui/code-highlight)

Code highlight built with highlight.js and UI

[View documentation](#)

## Installation

```bash
# With yarn
yarn add @react-ui/hooks @react-ui/ui @react-ui/code-highlight

# With npm
npm install @react-ui/hooks @react-ui/ui @react-ui/code-highlight
```
