# @react-ui/emotion

[![npm](https://img.shields.io/npm/dm/@react-ui/emotion)](https://www.npmjs.com/package/@react-ui/emotion)

Emotion bindings for @react-ui/ui

[View documentation](#)

## Installation

```bash
# With yarn
yarn add @react-ui/emotion @react-ui/ui @react-ui/hooks @emotion/react

# With npm
npm install @react-ui/emotion @react-ui/ui @react-ui/hooks @emotion/react
```
