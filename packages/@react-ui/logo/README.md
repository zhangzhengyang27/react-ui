# @react-ui/logo

[![npm](https://img.shields.io/npm/dm/@react-ui/logo)](https://www.npmjs.com/package/@react-ui/logo)

UI logo as react component

[View documentation](#)

## Installation

```bash
# With yarn
yarn add @react-ui/logo

# With npm
npm install @react-ui/logo
```

Then import styles:

```tsx
import '@react-ui/logo/styles.css';
```
