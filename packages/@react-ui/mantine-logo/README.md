# @react-ui/mantine-logo

[![npm](https://img.shields.io/npm/dm/@react-ui/mantine-logo)](https://www.npmjs.com/package/@react-ui/mantine-logo)

Mantine logo as react component

[View documentation](https://mantine.dev/)

## Installation

```bash
# With yarn
yarn add @react-ui/mantine-logo

# With npm
npm install @react-ui/mantine-logo
```

Then import styles:

```tsx
import '@react-ui/mantine-logo/styles.css';
```
