# Mantine modals manager

[![npm](https://img.shields.io/npm/dm/@react-ui/modals)](https://www.npmjs.com/package/@react-ui/modals)

Manage modals state

[View documentation](https://mantine.dev/)

## Installation

```bash
# With yarn
yarn add @react-ui/hooks @react-ui/ui @react-ui/modals

# With npm
npm install @react-ui/hooks @react-ui/ui @react-ui/modals
```
