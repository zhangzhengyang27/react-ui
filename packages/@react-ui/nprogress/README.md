[Documentation](https://mantine.dev/)

## Installation

```bash
# With yarn
yarn add @react-ui/nprogress @react-ui/ui @react-ui/hooks

# With npm
npm install @react-ui/nprogress @react-ui/ui @react-ui/hooks
```
