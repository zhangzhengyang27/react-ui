# UI Store

[![npm](https://img.shields.io/npm/dm/@react-ui/store)](https://www.npmjs.com/package/@react-ui/store)

Global state manager for `@react-ui/notifications`, `@react-ui/nprogress`, `@react-ui/spotlight` and other UI packages.

[View documentation](#)

## Installation

```bash
# With yarn
yarn add @react-ui/store

# With npm
npm install @react-ui/store
```
