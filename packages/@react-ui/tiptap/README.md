# UI tiptap

[![npm](https://img.shields.io/npm/dm/@react-ui/tiptap)](https://www.npmjs.com/package/@react-ui/tiptap)

Rich text editor based on [tiptap](https://tiptap.dev/)

[View documentation](#)

## Installation

```bash
# With yarn
yarn add @react-ui/tiptap @react-ui/ui @react-ui/hooks @tiptap/react @tiptap/extension-link

# With npm
npm install @react-ui/tiptap @react-ui/ui @react-ui/hooks @tiptap/react @tiptap/extension-link
```
