[View documentation](#)

## Installation

```bash
# With yarn
yarn add @xiaoye-react/emotion @xiaoye-react/ui @xiaoye-react/hooks @emotion/react

# With npm
npm install @xiaoye-react/emotion @xiaoye-react/ui @xiaoye-react/hooks @emotion/react
```
