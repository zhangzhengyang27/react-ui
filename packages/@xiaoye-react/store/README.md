# UI Store

[![npm](https://img.shields.io/npm/dm/@xiaoye-react/store)](https://www.npmjs.com/package/@xiaoye-react/store)

Global state manager for `@xiaoye-react/notifications`, `@xiaoye-react/nprogress`, `@xiaoye-react/spotlight` and other UI packages.

[View documentation](#)

## Installation

```bash
# With yarn
yarn add @xiaoye-react/store

# With npm
npm install @xiaoye-react/store
```
