# UI tiptap

[![npm](https://img.shields.io/npm/dm/@xiaoye-react/tiptap)](https://www.npmjs.com/package/@xiaoye-react/tiptap)

Rich text editor based on [tiptap](https://tiptap.dev/)

[View documentation](#)

## Installation

```bash
# With yarn
yarn add @xiaoye-react/tiptap @xiaoye-react/ui @xiaoye-react/hooks @tiptap/react @tiptap/extension-link

# With npm
npm install @xiaoye-react/tiptap @xiaoye-react/ui @xiaoye-react/hooks @tiptap/react @tiptap/extension-link
```
